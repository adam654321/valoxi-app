7f. Equivalent production SELECT
```sql
SELECT bs.id AS balance_sheet_id, bs.financial_period_id,
       fp.fiscal_year, fp.period_end, fp.source_tier,
       bs.trade_debtors
FROM balance_sheets bs
INNER JOIN financial_periods fp
  ON bs.financial_period_id = fp.id
WHERE bs.target_company_id = 251
  AND fp.fiscal_year = 2026
  AND fp.period_end <= CURRENT_DATE
ORDER BY fp.period_end DESC
LIMIT 1;
```
