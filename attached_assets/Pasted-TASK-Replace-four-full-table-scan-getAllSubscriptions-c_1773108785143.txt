TASK: Replace four full-table-scan getAllSubscriptions() calls in the 
Stripe webhook handler with a single targeted indexed lookup.

CONTEXT:
Every Stripe webhook event for subscription lifecycle (updated, deleted, 
invoice paid, invoice payment failed) currently fetches every row in the 
subscriptions table to find one matching row by stripeSubscriptionId. 
At scale this is a full table scan per event. The stripeSubscriptionId 
column already has a unique index in the schema, so a direct lookup is 
O(1). This change adds one new repository method and replaces four 
identical call sites in the webhook handler.

CHANGE 1 — server/repositories/billing.repository.ts

Add this new method to the BillingRepository class, immediately after 
the getByCompanyId method (after its closing brace, before 
getBetaPlanOverride):

  async getByStripeSubscriptionId(
    stripeSubscriptionId: string
  ): Promise<Subscription | null> {
    const [row] = await db
      .select()
      .from(subscriptions)
      .where(eq(subscriptions.stripeSubscriptionId, stripeSubscriptionId));
    return row ?? null;
  }

No other changes to this file.

CHANGE 2 — server/routes/billing.routes.ts

Replace all four identical two-line patterns in the webhook handler.
Each looks exactly like this (the variable name is either 
`subscription.id` or `subscriptionId` depending on the event block):

  const allSubs = await billingRepository.getAllSubscriptions();
  const matchingSub = allSubs.find(
    (s) => s.stripeSubscriptionId === subscription.id
  );

or:

  const allSubs = await billingRepository.getAllSubscriptions();
  const matchingSub = allSubs.find(
    (s) => s.stripeSubscriptionId === subscriptionId
  );

Replace each two-line pattern with a single line:

  // For customer.subscription.updated (line ~202) and 
  // customer.subscription.deleted (line ~245):
  const matchingSub = await billingRepository.getByStripeSubscriptionId(subscription.id);

  // For invoice.paid (line ~273) and invoice.payment_failed (line ~310):
  const matchingSub = await billingRepository.getByStripeSubscriptionId(subscriptionId);

The four if (matchingSub) guards and all matchingSub.userCompanyId 
accesses below each call site are unchanged — they work identically 
since getByStripeSubscriptionId returns Subscription | null.
