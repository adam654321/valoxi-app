STEP 1: Create client/src/components/portal/DdCollection.tsx

Create a new component for the DD requirements checklist with upload capability.

Props:
```typescript
interface DdCollectionProps {
  token: string;
  onDocumentUploaded: () => void;  // callback to refetch portal data
}
```

The component should:

a) FETCH DD REQUIREMENTS

Use useQuery to fetch from the new endpoint:
```typescript
const { data: ddData, refetch: refetchDd } = useQuery({
  queryKey: ['portal-dd-requirements', token],
  queryFn: async () => {
    const res = await fetch(`/api/v2/portal-submit/${token}/dd-requirements`);
    if (!res.ok) throw new Error('Failed to fetch requirements');
    return res.json();
  },
});
```

b) RENDER A COMPLETION SUMMARY AT THE TOP

Show a progress bar and summary:
- "Due Diligence Documents" as the section title
- Subtitle: "Please upload the requested documents against each requirement below."
- Progress bar showing: X of Y requirements have documents (use summary.total and count of non-not_started statuses)
- Completion percentage

c) RENDER CATEGORIES AS COLLAPSIBLE SECTIONS

For each category in ddData.categories:
- Collapsible header (click to expand/collapse) showing:
  - Category name (e.g. "Corporate Documents", "Financial Records")

  - Chevron icon for expand/collapse state
