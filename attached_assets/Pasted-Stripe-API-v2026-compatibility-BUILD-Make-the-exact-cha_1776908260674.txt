Stripe API v2026 compatibility — BUILD. Make the exact changes below in the order given. Do not deviate.

Goal: Stripe's current API (v2026-02-25 and later) has deprecated the coupon parameter on stripe.customers.update. Using it returns HTTP 400 "Received unknown parameter: coupon". Replace every instance with the current syntax that uses the discounts array.

The bug was diagnosed from a live Stripe API log showing:
  POST /v1/customers/cus_XXX
  Body: { "coupon": "8GXzaftB" }
  Response: 400 Received unknown parameter: coupon

Three call sites to fix:
- server/routes/billing.routes.ts around line 709 (in /checkout handler — caught the error, returned "Could not apply assigned discount")
- server/cron/billing.cron.ts around line 387 (in the daily free-months transition job — silently fails every day at 09:15 London for 5D New Member transitions)
- server/services/promo-code.service.ts around line 246 (in claimCode — may be dead code after 6C2 retirement of /register, but still present in file)

File: server/routes/billing.routes.ts

Locate the stripe.customers.update call inside the /checkout handler, around lines 707-719. Current:

  if (resolvedCoupon && customerId) {
    try {
      await stripe.customers.update(customerId, {
        coupon: resolvedCoupon.stripeCouponId,
      } as any);
      console.log(`[Billing] attached customer-level coupon ${resolvedCoupon.stripeCouponId} to customer ${customerId} (userCompanyId=${userCompanyId})`);
    } catch (err: any) {
      console.error(`[Billing] Failed to attach coupon ${resolvedCoupon.stripeCouponId} to customer ${customerId}:`, err);
      return res.status(500).json({
        error: 'coupon_attach_failed',
        message: 'Could not apply assigned discount. Please contact support.',
      });
    }
  }

Replace with:

  if (resolvedCoupon && customerId) {
    try {
      await stripe.customers.update(customerId, {
        discounts: [{ coupon: resolvedCoupon.stripeCouponId }],
      });
      console.log(`[Billing] attached customer-level coupon ${resolvedCoupon.stripeCouponId} to customer ${customerId} (userCompanyId=${userCompanyId})`);
    } catch (err: any) {
      console.error(`[Billing] Failed to attach coupon ${resolvedCoupon.stripeCouponId} to customer ${customerId}:`, err);
      return res.status(500).json({
        error: 'coupon_attach_failed',
        message: 'Could not apply assigned discount. Please contact support.',
      });
    }
  }

Key changes:
- coupon: X becomes discounts: [{ coupon: X }]
- Dropped the as any cast since the new syntax is valid in current Stripe types. If TypeScript complains, re-add as any temporarily and flag it in verification.
