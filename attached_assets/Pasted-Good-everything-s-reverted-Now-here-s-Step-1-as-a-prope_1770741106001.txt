1. Create shared/schema/due-diligence.ts with three tables following the exact same patterns used in shared/schema/deal-documents.ts (pgTable, serial, varchar, text, integer, boolean, timestamp, createInsertSchema, zod types):
Table: dd_categories

id serial PK
refPrefix varchar(10) unique not null — e.g. "1", "2", "15"
categoryName varchar(255) unique not null
description text
sortOrder integer not null
isActive boolean default true
createdAt timestamp defaultNow

Table: dd_requirements

id serial PK
categoryId integer FK → dd_categories.id, not null
refNumber varchar(10) unique not null — e.g. "1.1", "2.3", "15.7"
documentName varchar(500) not null
priority varchar(20) not null — values: "Mandatory", "Advisory", "Adds Value"
guidance text
collectionStage integer default 2
sortOrder integer not null
isActive boolean default true
createdAt timestamp defaultNow

Table: dd_requirement_status

id serial PK
requirementId integer FK → dd_requirements.id, not null
targetCompanyId integer FK → targetCompanies.id, not null
status varchar(30) default "not_started" not null — values: "not_started", "in_progress", "ready", "na"
notes text
documentId integer FK → documents.id (nullable, links to buyer-side uploaded doc)
externalSubmissionId integer FK → externalDocumentSubmissions.id (nullable, links to portal upload)
reviewedBy integer FK → users.id (nullable)
reviewedAt timestamp (nullable)
updatedBy integer FK → users.id (nullable)
createdAt timestamp defaultNow
updatedAt timestamp defaultNow

Create insert schemas (omitting id, createdAt, updatedAt, reviewedAt) and export all types (DdCategory, InsertDdCategory, DdRequirement, InsertDdRequirement, DdRequirementStatus, InsertDdRequirementStatus).
2. Add to shared/schema/index.ts: Add export * from './due-diligence'; after the deal-documents export.
3. Add relations to shared/schema/relations.ts:

Import ddCategories, ddRequirements, ddRequirementStatus from ./due-diligence
ddCategoriesRelations: has many ddRequirements
ddRequirementsRelations: belongs to ddCategories (categoryId), has many ddRequirementStatus
ddRequirementStatusRelations: belongs to ddRequirements (requirementId), belongs to targetCompanies (targetCompanyId), belongs to documents (documentId), belongs to externalDocumentSubmissions (externalSubmissionId), belongs to users as reviewedByUser (reviewedBy)
