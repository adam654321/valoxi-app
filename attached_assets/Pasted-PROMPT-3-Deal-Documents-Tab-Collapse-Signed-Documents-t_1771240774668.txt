PROMPT 3: Deal Documents Tab — Collapse Signed Documents to Heading
Context for Replit:
In the portal (client/src/components/enhanced-portal-display.tsx), the Deal Documents tab now shows the NDA, offer letters, and HoT. Currently the signed NDA shows as a simple card, but the OfferReview and HoTReview components always render in full regardless of status.
We want accepted/signed documents to collapse to a compact heading row by default. Documents that still need action (sent, viewed, countered) should remain fully expanded. The user can click to expand a collapsed document and view its full content.
Prompt:
In client/src/components/enhanced-portal-display.tsx, update the Deal Documents tab content to use collapsible cards for accepted/signed deal documents.

Import Collapsible, CollapsibleTrigger, CollapsibleContent from "@/components/ui/collapsible" if not already imported (check the imports — it may already be imported elsewhere in the file). Also import ChevronDown and ChevronRight from lucide-react if not already imported.

Add a state variable with the other useState declarations:
const [expandedDealDocs, setExpandedDealDocs] = useState<Set<string>>(new Set());

Add a toggle helper:
const toggleDealDoc = (docKey: string) => {
  setExpandedDealDocs(prev => {
    const next = new Set(prev);
    if (next.has(docKey)) next.delete(docKey);
    else next.add(docKey);
    return next;
  });
};
