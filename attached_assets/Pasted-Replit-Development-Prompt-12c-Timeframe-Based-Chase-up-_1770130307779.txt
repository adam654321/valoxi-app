Replit Development Prompt 12c: Timeframe-Based Chase-up System
Role: Expert Full-Stack Developer (Node.js/Express/React/PostgreSQL) Task: Implement an intelligent document chase-up system that respects agreed timeframes before sending automated reminders.

Context
We are building an M&A deal flow management tool. We successfully implemented "Prompt 12b" which tracks document submissions. Now we need "Prompt 12c" to automate the "chasing" of these documents (email reminders) but in a respectful, professional way that only alerts internal users when necessary.

Goals
Timeframe Management: Allow users to set an "agreed submission timeframe" (e.g., 14 days) when creating a portal link. No chase-up emails should be sent before this deadline.
Progressive Escalation: If the deadline passes, start a 4-email sequence (Gentle -> Firm -> Urgent -> Final).
Internal Alerts: Notify the internal team only on the 3rd and 4th emails, or if manual intervention is required.
Dashboard: Provide a view to monitor all active chase-ups.

2. Backend Logic (Chase-Up Manager)
Create a new service server/services/chase-up.manager.ts to handle the logic.

Requirements:

setPortalTimeframe(portalTokenId, timeframeDays, userId):

Calculates submissionDeadline = now + timeframeDays.
Updates portal_access_tokens.
Creates a chase_up_schedules record.
Call this from PortalService.createToken.
processChaseUpSchedules():

Find active schedules where submissionDeadline <= today and isCompleted = false.
Logic:
If daysOverdue >= 0 AND email 1 not sent -> Send Email 1 (Gentle).
If daysOverdue >= 2 AND email 2 not sent -> Send Email 2 (Firm).
If daysOverdue >= 5 AND email 3 not sent -> Send Email 3 (Urgent) + Internal Alert.
If daysOverdue >= 8 AND email 4 not sent -> Send Email 4 (Final) + Internal Alert.
If daysOverdue >= 11 -> Trigger "Manual Intervention Required" status.
sendChaseUpEmail(schedule, type):

Use emailApiService to send the actual email.
Log the email in chase_up_emails.
Update portal_access_tokens chase-up status.
Integration:

Update
