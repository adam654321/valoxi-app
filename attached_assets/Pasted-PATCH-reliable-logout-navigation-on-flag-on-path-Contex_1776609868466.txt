PATCH — reliable logout navigation on flag-on path
Context: Clerk's signOut({ redirectUrl }) in @clerk/react@6.4.2 does not reliably navigate on wouter apps. Symptom is that clicking Log out clears cookies but does not navigate — the user stays on the dashboard until another interaction triggers a re-render. Fix is to make the navigation explicit via window.location.href, mirroring the flag-off path.
Two file changes. Zero backend touch. No assess needed.
STEP 1 — modify client/src/components/layout/NavUser.tsx
Inside logoutMutation.mutationFn, change the flag-on branch from:
if (clerkEnabled) {
  await signOut({ redirectUrl: "/sign-in" });
}
to:
if (clerkEnabled) {
  await signOut();
  window.location.href = "/sign-in";
}
No other changes to this file. The flag-off onSuccess branch (window.location.href = "/login") stays exactly as-is. Update the inline comment above the Clerk call to reflect the new behaviour, e.g. "// Clerk clears __session, then explicit navigation to /sign-in to avoid redirectUrl reliability issues in v6.4.2."
