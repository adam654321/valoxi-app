PROMPT 3 — Physical signature block
We are building an offline document delivery flow for Valoxi. When a buyer downloads an offer letter or HoT as a Word document to send by email or post, it needs a physical wet-signature block at the end instead of the digital capture block used in the portal. We need to add a new exported function to the document HTML builders. In server/utils/document-html-builders.ts add a new exported function called buildPhysicalSignatureBlock at the very end of the file after the existing buildHoTHtml function. The function takes three parameters: documentType as string, docData as any, and documentId as number. It returns a string of HTML. Inside the function extract buyerSignatoryName, buyerSignatoryTitle, buyerCompanyName, and sellerCompanyName from docData with empty string fallbacks. Generate a generatedDate using new Date().toLocaleDateString with en-GB locale and options day numeric month long year numeric. Create a docTitleMap object mapping nda to Non-Disclosure Agreement, offer_letter to Offer Letter, and heads_of_terms to Heads of Terms. Create a buyerLabelMap mapping nda to Disclosing Party (Buyer), offer_letter to Buyer, heads_of_terms to Buyer. Create a sellerLabelMap mapping nda to Receiving Party (Seller), offer_letter to Seller, heads_of_terms to Seller. Create an inner helper function called line that takes a label string and returns a two-element HTML string: a paragraph with the label followed by a colon, and a div with style border-bottom 1px solid hash 333, width 100%, height 32px, margin-bottom 16px acting as a blank signature line. The return value of buildPhysicalSignatureBlock should be a template literal of HTML. The outer wrapper div should have margin-top 48px, padding-top 32px, border-top 2px solid hash 333, and font-family Arial sans-serif. Inside render a centered h2 with text EXECUTION in uppercase with letter-spacing 1px. Below that a centered paragraph saying IN WITNESS WHEREOF, the parties hereto have executed this then the docTitle from the map then the phrase on the dates written below. Then render a div with display flex, gap 48px, justify-content space-between. Inside that div render two equal child divs each with flex 1, border 1px solid hash ccc, border-radius 6px, padding 20px. The left div should show the buyerLabelMap value in an uppercase small paragraph, then use the line helper for Full name (print), Signature, and Title / Position, then a paragraph showing the text On behalf of: followed by the buyerCompanyName, then the line helper for Date signed. The right div should show the sellerLabelMap value in an uppercase small paragraph, then use the line helper for Full name (print), Signature, and Title / Position, then a paragraph showing Company: followed by sellerCompanyName, then the line helper for Date signed. After both columns close the flex div and render a footer div with background hash f5f7fa, border 1px solid hash ddd, border-radius 4px, padding 12px 16px, text-align center, containing a paragraph with font-size 11px and color hash 888 saying: This document was generated by Valoxi on then the generatedDate then a middot then Reference: VAL- then the documentId. Do not touch the existing buildSignatureBlock or any other function. After the change confirm buildPhysicalSignatureBlock is exported, the existing functions are unchanged, TS error count remains at 6, and only document-html-builders.ts was modified.
