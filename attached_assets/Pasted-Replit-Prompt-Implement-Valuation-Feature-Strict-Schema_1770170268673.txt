The Feature: "Valuation & Deal Structure". Why: Once we have extracted the raw financial data (Revenue, P&L, Balance Sheet) from the uploaded PDFs, the user needs a place to:

View & Verify this data (Read-Only Historic view).
Normalize the earnings (Add-back personal expenses aka "Adjustments").
Structure the Deal (Decide how much to pay and how to fund it—e.g., how much debt vs equity).
The Flow: Documents Uploaded -> Data Extracted (JSON) -> Financials Database (THIS TASK) -> Valuation Modeling

I need you to implement the Valuation & Deal Structure feature using a strict financial schema.

shared/schema.ts
)
Please implement the following exact table structure using drizzle-orm.

1. Financial Periods
Anchor table for all financial data.

export const financialPeriods = pgTable("financial_periods", {
  id: serial("id").primaryKey(),
  targetCompanyId: integer("target_company_id").references(() => targetCompanies.id).notNull(),
  periodLabel: varchar("period_label", { length: 50 }), // 'FY 2021'
  periodType: varchar("period_type", { length: 20 }).notNull(), // 'historic' | 'forecast'
  periodStart: date("period_start"),
  periodEnd: date("period_end"),
  fiscalYear: integer("fiscal_year"),
});
2. Core Financial Statements (Strict Columns)
Income Statements:

export const incomeStatements = pgTable("income_statements", {
  id: serial("id").primaryKey(),
  financialPeriodId: integer("financial_period_id").references(() => financialPeriods.id).notNull(),
  targetCompanyId: integer("target_company_id").references(() => targetCompanies.id).notNull(),
  // Core Metrics
  revenue: decimal("revenue"),
  costOfSales: decimal("cost_of_sales"),

  adminExpenses: decimal("administrative_expenses"),
  ebitda: decimal("ebitda"),
  operatingProfit: decimal("operating_profit"),
  netProfit: decimal("net_profit"),
  // Breakdowns (JSON for flexibility within strict structure)
  revenueBreakdown: json("revenue_breakdown"),

export const balanceSheets = pgTable("balance_sheets", {

  shareCapital: decimal("share_capital"),
  retainedEarnings: decimal("retained_earnings"),
