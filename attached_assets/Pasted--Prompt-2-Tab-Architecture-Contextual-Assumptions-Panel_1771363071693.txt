## 3. Make `AssumptionsPanel` Contextually Aware

### Add `activeTab` Prop

In `AssumptionsPanel.tsx`, add to the interface:

### Add Contextual Open/Close Logic

Add a ref to track user manual overrides, and a `useEffect` that sets default open/close states based on the active tab:

```typescript
const userOverrideRef = useRef<Set<string>>(new Set());

// Wrap the existing onOpenChange handlers to track user overrides
const handleGrowthToggle = (open: boolean) => {
  userOverrideRef.current.add('growth');
  setGrowthOpen(open);
};
const handleDebtToggle = (open: boolean) => {
  userOverrideRef.current.add('debt');
  setDebtOpen(open);
};
const handleSynergiesToggle = (open: boolean) => {
  userOverrideRef.current.add('synergies');
  setSynergiesOpen(open);
};
const handleExitToggle = (open: boolean) => {
  userOverrideRef.current.add('exit');
  setExitOpen(open);
};

useEffect(() => {
  // Only auto-toggle sections the user hasn't manually touched this tab session
  const defaults: Record<string, Record<string, boolean>> = {
    'dashboard': { growth: false, debt: false, synergies: false, exit: true },
    'projections': { growth: true, debt: false, synergies: true, exit: false },
    'cash-debt': { growth: false, debt: true, synergies: false, exit: false },
    'returns-exit': { growth: false, debt: true, synergies: false, exit: true },
    'risk': { growth: false, debt: false, synergies: false, exit: true },
  };

  const tab = activeTab || 'projections';
  const d = defaults[tab] || defaults['projections'];

  if (!userOverrideRef.current.has('growth')) setGrowthOpen(d.growth);
  if (!userOverrideRef.current.has('debt')) setDebtOpen(d.debt);
  if (!userOverrideRef.current.has('synergies')) setSynergiesOpen(d.synergies);
  if (!userOverrideRef.current.has('exit')) setExitOpen(d.exit);

  // Reset overrides on tab change so contextual defaults apply fresh next time
  userOverrideRef.current.clear();
}, [activeTab]);
```

### 4b. Reduce Growth Badge Noise in `PLProjectionsSection.tsx`

The `growthBadge` function is called on every bold row in the table view, showing (↑3.2%, ↓1.1%) on every line. This creates visual noise.

Change the condition so growth badges only appear on these summary rows: **Revenue, Gross Profit, EBITDA, Net Profit, Free Cash Flow**. 

In the table rendering, the growth badge is applied with this condition:
```tsx
{row.bold && !row.margin && val !== null && prevVal !== null && prevVal !== 0 && (
  growthBadge(val!, prevVal!)
)}
```

Change to:
```tsx
{row.bold && !row.margin && !row.synergy && !row.indent && val !== null && prevVal !== null && prevVal !== 0 
  && ['Revenue', 'Gross Profit', 'EBITDA', 'Net Profit', 'Free Cash Flow'].includes(row.label) && (
  growthBadge(val!, prevVal!)
)}
```
