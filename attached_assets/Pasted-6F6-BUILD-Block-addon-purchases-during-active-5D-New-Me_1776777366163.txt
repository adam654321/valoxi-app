STEP 1: add getFreePeriodState helper to server/services/promo-code.service.ts

Append directly after isFiveDNewMember (end of file, after the getWaitlistPromoCopy block):

import type { Subscription } from '@shared/schema/billing';

export interface FreePeriodState {
  isActive: boolean;
  elapsedMonths: number;
  remainingMonths: number;
}

export function getFreePeriodState(subscription: Subscription): FreePeriodState {
  if (subscription.freeMonthsTotal <= 0 || !subscription.freeMonthsStartedAt) {
    return { isActive: false, elapsedMonths: 0, remainingMonths: 0 };
  }
  const elapsed = computeFreeMonthsElapsed(subscription.freeMonthsStartedAt);
  const remaining = Math.max(0, subscription.freeMonthsTotal - elapsed);
  const isActive = elapsed < subscription.freeMonthsTotal;
  return {
    isActive,
    elapsedMonths: elapsed,
    remainingMonths: remaining,
  };
}

- Helper is pure. No DB, no side effects. Reusable from the cron and from future callers without concern.
- Do not modify resolveCheckoutCoupon to use this helper in this cycle. Parallel refactor is not needed; resolveCheckoutCoupon is already correct and low-risk. Defer helper consolidation to 6H housekeeping.
