The fix is to fetch the latest deal model for the company and pass its id when downloading offer letters. In client/src/components/deal-documents/DealDocumentsSummary.tsx make the following changes. Add a new useQuery call inside the DealDocumentsSummary component body alongside the existing queries. It should have queryKey of the array containing the string /api/v2/deal-models/company and the targetCompanyId value. Then derive a variable called latestDealModelId as dealModelsData?.[0]?.id — this will be undefined if no deal model exists yet which is fine. Then find the handleOfflineDownload function — it currently calls apiRequest POST to /api/v2/deal-documents/create-offline with a body containing targetCompanyId and documentType. Update the body so that when documentType equals the string offer_letter and latestDealModelId is defined, it also includes dealModelId set to latestDealModelId in the request body.
