HOTFIX after Prompt 6: the clerk_user_id IS NOT NULL filter on getTeamMembers
is hiding legacy unlinked real users (not just shells). We discovered this
in manual dev testing — Viv has clerk_user_id NULL but a populated
password_hash, so she predates Clerk. The discriminator needs to be:

  is a shell (hide):    clerk_user_id IS NULL AND password_hash IS NULL
  is a real member:     clerk_user_id IS NOT NULL OR password_hash IS NOT NULL

DEV ONLY.
