It's time to execute the hardcoded gray color refactor. Please apply the following **systematic find-and-replace** across the entire `client/src/` directory — this covers all page files, components, and the extracted target-companies modules.

**The Mapping Rules:**

| Hardcoded class | Semantic replacement |
|---|---|
| `text-gray-900`, `text-gray-800`, `text-gray-700` | `text-foreground` |
| `text-gray-600`, `text-gray-500` | `text-muted-foreground` |
| `text-gray-400` | `text-muted-foreground/70` |
| `text-gray-300`, `text-gray-200`, `text-gray-100` | `text-muted-foreground/50` |
| `bg-gray-50`, `bg-gray-100`, `bg-gray-200` | `bg-muted` |
| `hover:bg-gray-50` | `hover:bg-muted/50` |
| `hover:bg-gray-100` | `hover:bg-muted` |
| `border-gray-200`, `border-gray-300`, `border-gray-400` | `border-border` |
| `border-gray-100` | `border-border/50` |
| `divide-gray-200` | `divide-border` |
| `divide-gray-100` | `divide-border/50` |
| All `dark:text-gray-*` classes | **Remove entirely** (CSS variables handle dark mode automatically) |
| All `dark:bg-gray-*` classes | **Remove entirely** (same reason) |
| All `dark:border-gray-*` and `dark:divide-gray-*` | **Remove entirely** |
| `dark:text-white` (paired with `text-gray-900`) | **Remove entirely** |

**Important nuances:**
- `bg-gray-800`, `bg-gray-900`, `bg-gray-950` only appear in `dark:` prefixed classes — remove them with the rest of the dark overrides
- Skeleton/loading state `bg-gray-200` classes = `bg-muted` is the correct replacement
- Empty-state icon classes like `text-gray-300` = `text-muted-foreground/50`
- `bg-white` used as a card surface = `bg-card`
- Do **NOT** touch any gray classes inside commented-out code or `.css` files
