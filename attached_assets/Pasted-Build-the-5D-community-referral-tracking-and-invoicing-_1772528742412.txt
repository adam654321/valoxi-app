Build the 5D community referral tracking and invoicing system. Do not start until you have read all relevant files.
Background:
5D community members get 3 months of Core free, then pay 25% off forever. 5D's organisation is invoiced monthly for all active free months consumed by their referred members. Two Stripe coupons exist in live mode — one for the free period, one for the ongoing discount.
Database changes:
Add the following columns to the subscriptions table:
sqlreferralSource VARCHAR(50) DEFAULT NULL,        -- e.g. '5d_community'
referralCode VARCHAR(50) DEFAULT NULL,           -- the code they used at signup
freeMonthsTotal INTEGER DEFAULT 0,              -- total free months granted (3 for 5D)
freeMonthsUsed INTEGER DEFAULT 0,               -- incremented monthly by cron
freeMonthsStartedAt TIMESTAMP DEFAULT NULL,     -- when free period began
communityDiscountCouponId VARCHAR(50) DEFAULT NULL  -- Stripe coupon ID for ongoing discount
Run db:push after schema change.
New referral code system:
Create server/services/referral.service.ts:

typescriptconst REFERRAL_CODES = {
  '5DCOMMUNITY': { source: '5d_community', freeMonths: 3, discountCouponId: 'A09JvJxx', freeCouponId: 'fRoxnZbY' },
}

Returns referral config or null if invalid
Add more codes here as new partnerships are added

Registration flow changes:
In server/routes/auth.routes.ts, accept an optional referralCode field in the registration body.
After successful registration and trial subscription creation:

If referralCode provided, call referral.service.validateReferralCode(code)
If valid, update the subscription row with: referralSource, referralCode, freeMonthsTotal, freeMonthsStartedAt: now()
Apply the free coupon to the Stripe customer: stripe.customers.update(stripeCustomerId, { coupon: freeCouponId })
Log a funnel event: referral.activated with { source, code, freeMonths }

Registration page changes:
In client/src/pages/register.tsx (or equivalent), add an optional "Referral Code" field below the other fields. Label: "Referral Code (optional)". Placeholder: "e.g. 5DCOMMUNITY". Submit alongside other registration fields.
Free months tracking cron:
In server/cron/billing.cron.ts, add a third job — runs on the 1st of each month at 09:15 UK time:

Queries all subscriptions where referralSource IS NOT NULL and freeMonthsUsed < freeMonthsTotal
For each: increments freeMonthsUsed by 1
If freeMonthsUsed >= freeMonthsTotal (free period ending):

Removes the free coupon from the Stripe customer
Applies the ongoing discount coupon: stripe.customers.update(stripeCustomerId, { coupon: communityDiscountCouponId })
Logs a funnel event: referral.free_period_ended
Sends a notification email to the user: "Your 3 free months are ending — you'll be charged £50.25/mo from [date]"
