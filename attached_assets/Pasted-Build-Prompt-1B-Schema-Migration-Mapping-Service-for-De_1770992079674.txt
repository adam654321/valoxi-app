The QOE prompt now returns three new fields per adjustment (defensibility_score, case_for_inclusion, case_for_exclusion) and a benchmark_range_used field in director salary analysis. We need to:
1. Add three new columns to the deal_model_adjustments table
2. Update the mapping service to store these new fields
3. Run a database migration

In the dealModelAdjustments table definition, add three new columns AFTER the existing "confidence" column and BEFORE the "status" column:

Find this line:

Add these three lines immediately after it:

  caseForInclusion: text("case_for_inclusion"),
  caseForExclusion: text("case_for_exclusion"),

ALTER TABLE deal_model_adjustments ADD COLUMN IF NOT EXISTS case_for_inclusion TEXT;
