TASK: Replace inline isSystemAdmin session checks in two billing admin 
routes with the proper isSystemAdmin middleware from auth.ts.

CONTEXT:
POST /admin/comp and GET /admin/subscriptions both guard themselves with 
a raw inline check: if (!req.session.isSystemAdmin) { return 403; }
This bypasses the TTL-aware cache refresh in the isSystemAdmin middleware,
meaning a revoked admin can retain access for up to 7 days (full session 
lifetime). The fix adds isSystemAdmin to the middleware chain of both 
routes and removes the now-redundant inline checks.

server/routes/billing.routes.ts
