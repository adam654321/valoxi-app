**Data Fetching (3 queries):**

1. **List existing deal models** for this company:
```
   GET /api/v2/deal-models/company/${companyId}
```
   Remember the API wraps responses in `{ success: true, data: ... }` — unwrap `.data` from the response.

2. **Get the selected/active deal model** with full details (adjustments + funding lines):
```
   GET /api/v2/deal-models/${selectedModelId}
```
   Only enabled when a model is selected.

3. **Get financial data** for the P&L display (keep the existing financial data endpoint as a fallback for reported EBITDA figures):
```
   GET /api/v2/financial-data/company/${companyId}/financials
```
