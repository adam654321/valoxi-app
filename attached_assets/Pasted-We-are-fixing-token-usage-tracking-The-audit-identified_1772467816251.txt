Token tracking works correctly when userId is provided — the issue is purely missing caller context
The four untracked callers are: gemini-expert-service.ts, gemini-document-classification-service.ts, gemini-step2-analysis-service.ts, website-analysis.service.ts
Read each file carefully before making changes — understand how context flows into each service before adding fields
