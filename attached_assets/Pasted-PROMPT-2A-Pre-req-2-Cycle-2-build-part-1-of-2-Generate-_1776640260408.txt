Step 1. Create the transformation script
Create a small one-shot TypeScript script at scripts/etl-waitlist-transform.ts that:
a) Reads the source file at attached_assets/waitlist_rows__2_.sql (adjust path if different)
b) Applies three transformations in order:

Replace \+00 suffix on timestamp literals. Use regex: /(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}(?:\.\d+)?)\+00/g replaced with $1. Track count of replacements.
Replace literal ARRAY[] with ARRAY[]::text[]. Track count of replacements.
Append  ON CONFLICT (id) DO NOTHING immediately before the closing semicolon. Use a replace anchored at the final ;.
c) Writes the transformed SQL to attached_assets/waitlist_rows_transformed.sql
d) Prints to stdout:
Source byte count and transformed byte count
Number of +00 suffixes stripped (expected: 46)
Number of ARRAY[] fixes applied (expected: 1)
Whether the ON CONFLICT (id) DO NOTHING clause was appended successfully (expected: true)
Number of VALUES tuples in the output (should still be 46)

The script should not connect to any database. It is a pure text transformation.
Step 2. Run the transformation script
Run: npx tsx scripts/etl-waitlist-transform.ts
Report the full stdout output.
