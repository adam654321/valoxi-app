Context
The funding structure currently has a rigid mapping: certain funding types (cash_equity, investor_equity) are treated as equity with no rate/term/repayment inputs, while others (asset_finance, senior_debt, etc.) show debt fields. This is too restrictive — real deal structures have funding sources like "Cash Flow Loans" and "Seller Financing" that are debt instruments but don't fit neatly into the predefined types. They end up classified as "Cash Equity" and then don't contribute to the DSCR calculation, which defeats the purpose.
Fix: Add isDebt flag to funding lines
This is a schema → calculator → backend → frontend change.
1. Schema change — shared/schema/deal-models.ts
Add a new boolean column to deal_model_funding_lines:
isDebt: boolean, default false
This determines whether the line contributes to debt service calculations (DSCR). When isDebt is true, the line must have interestRate and termMonths to calculate repayments.
Run drizzle-kit push after the schema change.
