**The Problem:**
Unlike the other protected API routes (e.g., `/api/v2/pipeline`, `/api/v2/documents`), this route is completely missing the `validateCsrfToken` middleware. Since this route handles sensitive write operations (like file uploads and data submissions from the portal), lacking CSRF protection leaves us vulnerable to Cross-Site Request Forgery attacks.
**Proposed Solution:**
I believe we simply need to apply the `validateCsrfToken` middleware to this route group in [server/routes/index.ts](cci:7://file:///c:/Users/AdamAuty/Downloads/MandA-Internal-Google-Brain%20%287%29/MandA-Internal-Google-Brain/server/routes/index.ts:0:0-0:0) like this:

app.use('/api/v2/portal-submit', portalLimiter, validateCsrfToken, portalSubmissionsRoutes);
\`\`\`
