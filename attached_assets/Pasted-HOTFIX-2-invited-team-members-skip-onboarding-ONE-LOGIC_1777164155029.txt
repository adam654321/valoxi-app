HOTFIX 2 — invited team members skip onboarding.

ONE LOGICAL CHANGE: invitees pre-created via the team invite flow should
not see the onboarding screen. Their company-level fields (companyName,
industry, companySize, country) are already set on the inviter's
userCompanies row, which the shell shares via userCompanyId. Their
jobTitle is collected by the invite dialog. The remaining onboarding
side-effect (onboardingCompleted=true) needs to be set at shell-create
time. hearAboutUs is intentionally left NULL because the invitee did not
hear about Valoxi through marketing — they were invited.

DEV ONLY.

================================================================
STEP 1 — Update the shell insert in createInvitationWithUserShell
================================================================
File: server/repositories/team.repository.ts
In the createInvitationWithUserShell method, find the
tx.insert(users).values({...}) block. Add two fields:

  onboardingCompleted: true,
  onboardingCompletedAt: new Date(),

The full block becomes:

  await tx.insert(users).values({
    email: input.email,
    firstName: input.firstName,
    lastName: input.lastName,
    jobTitle: input.jobTitle ?? null,
    userCompanyId: input.userCompanyId,
    currentCompanyId: input.userCompanyId,
    role: 'user',
    userRole: input.invitedRole,
    isCompanyAdmin: false,
    isActive: true,
    emailVerified: false,
    onboardingCompleted: true,
    onboardingCompletedAt: new Date(),
  } as InsertUser);

Rationale: companyName, industry, companySize, country live on
userCompanies, not users — they are inherited automatically via
userCompanyId. jobTitle is already populated from the invite dialog.
hearAboutUs stays NULL because the invitee did not hear about Valoxi
through marketing; populating it with a placeholder would pollute funnel
analytics. checklistCompleted stays false (schema default) so the
invitee sees the dashboard activation checklist on first sign-in, which
is appropriate first-time-user UX.
