CoreAnalysisSummaryView — UX Fixes
Context
The CoreAnalysisSummaryView was built in Step 8. Three specific issues need fixing.
Do not change anything else — these are targeted fixes only.

Fix 1 — Remove blur on hover from expert takeaway cards (Section 6)
The expert takeaway cards in the "Key Takeaways" section currently apply a blur
or opacity effect when the user hovers over them. Remove this entirely.
The cards should remain fully readable at all times.
The lock icon / "Upgrade to Professional" message on hover is fine to keep —
but the card content underneath must NOT blur, dim, or change opacity.
Find the hover styles on the expert takeaway cards and remove any:

blur, backdrop-blur, filter: blur()
opacity reduction on hover
Any CSS that obscures the card content on hover

The lock overlay message can still appear on hover — just ensure it sits on top
of fully visible card content, not over blurred/dimmed content.

Fix 2 — Remove upgrade button from individual expert cards
Each expert takeaway card currently shows an upgrade prompt or button on hover.
Remove the upgrade button/CTA from the individual cards entirely.
The only upgrade prompt should be the dedicated Section 8 upgrade block at the bottom
of the page. Users do not need to be nudged on every single card.
Keep the lock icon on hover if it helps communicate that drill-down is not available —
but remove any button, link, or "Upgrade to Professional" text from the card hover state.
A simple 🔒 icon is sufficient.

Fix 3 — Redesign the upgrade section (Section 8)
The current upgrade prompt at the bottom is functional but plain. Redesign it to look
polished and compelling without being aggressive.

Implementation notes:

Outer container: subtle gradient background (e.g. light indigo/blue to white),
rounded corners, tasteful border — NOT a garish sales banner
Heading: "Unlock the full picture" with a lock/unlock icon — clear but not shouty
Brief subtext: one sentence explaining what Professional unlocks
Feature grid: 6 tiles in a 2-column or 3-column responsive grid
Each tile: icon + feature name (bold, 2-3 words) + brief description (1 line)
CTA button: primary colour, includes the price "from £127/mo" so users know the cost
upfront — no bait and switch. Link to /billing.
Below button: small grey text "No commitment. Cancel anytime." — reduces friction
The whole section should feel like a natural part of the page, not a popup or ad
