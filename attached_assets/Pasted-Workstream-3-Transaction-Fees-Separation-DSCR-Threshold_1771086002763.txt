PROMPT 3A: Calculator Changes + DSCR Thresholds
FEATURE: Separate transaction fees from deal funding target + fix DSCR thresholds

Two changes in this prompt: (1) the funding stack should target the offer price only, not offer price + fees, and (2) the DSCR thresholds need correcting.

CONTEXT: Currently the funding stack's "Total to Fund" includes transaction fees (legal DD, accounting DD, broker, etc.). This is wrong — the funding stack should target the cost of the business (offer price) only. Transaction fees are a separate cost that gets added at the end in the deal summary to show the total outlay.

STEP 1: UPDATE THE CALCULATOR

File: shared/calculators/deal-model.calc.ts

In the calculateFullDealModel function, change what gets passed to calculateFundingStack. Currently it passes fees.totalFundingRequired (which is offerPrice + totalFees). Change it to pass just the offerPrice:

Current:
```typescript
const funding = calculateFundingStack(fundingLines, fees.totalFundingRequired);
```

New:
```typescript
const funding = calculateFundingStack(fundingLines, offerPrice);
```

Then update the adjusted totals calculation that follows. Currently:
```typescript
const adjustedTotalFees = fees.totalFees + funding.totalArrangementFees;
const adjustedTotalFundingRequired = fees.totalFundingRequired + funding.totalArrangementFees;
const adjustedFundingGap = Math.round((adjustedTotalFundingRequired - funding.totalFunded) * 100) / 100;
```

Change to:
```typescript
const adjustedTotalFees = fees.totalFees + funding.totalArrangementFees;
const adjustedTotalFundingRequired = offerPrice + adjustedTotalFees;
const adjustedFundingGap = Math.round((offerPrice - funding.totalFunded) * 100) / 100;
```

The key difference: fundingGap is now calculated against offerPrice only (the deal cost), not offerPrice + fees. The totalFundingRequired still represents the all-in number (deal + fees) for the summary display.

Change them to:
- strong: > 1.8
- adequate: >= 1.4
- tight: >= 1.0
- unfundable: < 1.0

Update the if/else block:
