The beta feedback screenshot upload and serving both use the old Replit Object Storage SDK (@replit/object-storage) which is broken in deployed environments. This needs migrating to R2 via fileStorageService, the same as all other file uploads.
1. In server/routes/beta-feedback.routes.ts, find the upload handler for screenshots. Replace the createStorageClient().uploadFromBytes() call with fileStorageService:
Find:
typescriptconst key = `.private/beta-feedback/${Date.now()}-${...}.${ext}`;
await createStorageClient().uploadFromBytes(key, req.file.buffer);
screenshotUrl = key;
Replace with:
typescriptconst key = fileStorageService.generateKey('beta-feedback', req.file.originalname);
await fileStorageService.upload(key, req.file.buffer);
screenshotUrl = key;
2. Replace the screenshot serving route — find the router.get('/screenshot/:key(*)') handler and replace it entirely:
typescriptrouter.get('/screenshot/:key(*)', isAuthenticated, asyncHandler(async (req: Request, res: Response) => {
  const key = req.params.key;
  if (!key) {
    return res.status(400).json({ success: false, message: 'Invalid key' });
  }
  try {
    const buffer = await fileStorageService.download(key);
    const ext = key.split('.').pop()?.toLowerCase() || 'png';
    const mimeMap: Record<string, string> = {
      png: 'image/png',
      jpg: 'image/jpeg',
      jpeg: 'image/jpeg',
      gif: 'image/gif',
      webp: 'image/webp',
    };
    res.setHeader('Content-Type', mimeMap[ext] || 'image/png');
    res.setHeader('Cache-Control', 'private, max-age=3600');
    return res.send(buffer);
  } catch {
    return res.status(404).json({ success: false, message: 'Screenshot not found' });
  }
}));
3. Add the import at the top of the file if not already present:
typescriptimport { fileStorageService } from '../services/file-storage.service';
4. Remove the createStorageClient function and the @replit/object-storage import entirely from this file — they are no longer needed.
Note on existing screenshots: Any screenshots uploaded before this fix used the old SDK and likely never saved successfully. Those records in the DB will return 404 — that is expected and acceptable. New screenshots will work correctly.
Confirm clean restart with no TypeScript errors.
