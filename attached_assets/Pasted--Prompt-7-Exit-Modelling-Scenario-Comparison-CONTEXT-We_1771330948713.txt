# Prompt 7: Exit Modelling & Scenario Comparison

## CONTEXT

We are building the Value Creation Modeller for an M&A CRM platform. Prompts 1–6 delivered all infrastructure, calculator functions, and Sections 1, 4, 5, and 6. This is the **final section** — Section 7.

### What already exists:

- **Calculator**: `shared/calculators/value-creation.calc.ts` — includes `calculateScenarios()` and `calculateReturns()`
- **Orchestrator**: `client/src/components/target-company/ValueCreationModeller.tsx` — computes projections, returns, and sensitivity for the *active* scenario only

The orchestrator currently has these available:
- `baseYearData` — `BaseYearData | null`
- `activeAssumptions` — `YearAssumptions[]` (for the currently selected scenario tab)
- `synergyInputs` — `SynergyInput[]` (for the currently selected scenario)
- `fundingLineInputs` — `FundingLineForProjection[]`
- `exitAssumptions` — `ExitAssumptionsType`
- `entryEquity` — `number`
- `entryMultiple` — `number`
- `totalDebt` — `number`
- `totalFees` — `number`
- `projections` — `ProjectedYear[]`
- `returnMetrics` — `ReturnMetrics | null`
- `vcData` — contains `scenarios`, `assumptions`, `synergies` for ALL three scenarios (bear/base/bull)

The `calculateScenarios()` function signature:
```typescript
function calculateScenarios(
  baseYear: BaseYearData,
  assumptions: YearAssumptions[],
  synergies: SynergyInput[],
  fundingLines: FundingLineForProjection[],
  bearMultipliers?: ScenarioMultipliers,
  bullMultipliers?: ScenarioMultipliers
): { bear: ProjectedYear[]; base: ProjectedYear[]; bull: ProjectedYear[] }
```

The `ScenarioMultipliers` type:
```typescript
interface ScenarioMultipliers {
  revenueGrowthMultiplier: number;
  costPressureAdjustment: number;
}
```

Each scenario in `vcData.scenarios` has `revenueGrowthMultiplier` and `costPressureAdjustment` fields (stored as decimal strings).

### 1c. Add useMemo block for multi-scenario data

Add this **after** the `sensitivityData` useMemo block. This computes projections and returns for all three scenarios simultaneously, using the **base case assumptions** modified by each scenario's multipliers (which is exactly what `calculateScenarios` does):

```tsx
const scenarioComparison = useMemo(() => {
  if (!baseYearData || activeAssumptions.length === 0 || entryEquity <= 0 || !vcData?.scenarios) return null;

  // Get the base scenario's assumptions (used as the input that gets modified by multipliers)
  const baseScenario = vcData.scenarios.find(s => s.scenarioType === 'base');
  const bearScenario = vcData.scenarios.find(s => s.scenarioType === 'bear');
  const bullScenario = vcData.scenarios.find(s => s.scenarioType === 'bull');

  if (!baseScenario) return null;

  // Get the base case assumptions (the ones used as input to calculateScenarios)
  const baseAssumptions = vcData.assumptions
    .filter(a => a.scenarioId === baseScenario.id)
    .sort((a, b) => a.year - b.year)
    .map(a => ({
      year: a.year,
      revenueGrowthPercent: toNum(a.revenueGrowthPercent),
      costOfSalesGrowthPercent: toNum(a.costOfSalesGrowthPercent),
      adminCostGrowthPercent: toNum(a.adminCostGrowthPercent),
      staffCostGrowthPercent: toNum(a.staffCostGrowthPercent),
      depreciationGrowthPercent: toNum(a.depreciationGrowthPercent),
      capexPerYear: toNum(a.capexPerYear),
      workingCapitalPercent: toNum(a.workingCapitalPercent),
      taxRatePercent: toNum(a.taxRatePercent),
    }));

  // Get base case synergies
  const baseSynergies = vcData.synergies
    .filter(s => s.scenarioId === baseScenario.id)
    .map(s => ({
      synergyType: s.synergyType as 'revenue' | 'cost',
      name: s.name,
      targetValue: toNum(s.targetValue),
      realisationByYear: [
        toNum(s.realisationY1) / 100,
        toNum(s.realisationY2) / 100,
        toNum(s.realisationY3) / 100,
        toNum(s.realisationY4) / 100,
        toNum(s.realisationY5) / 100,
      ],
      implementationCost: toNum(s.implementationCost),
    }));

  if (baseAssumptions.length === 0) return null;

  const bearMult: ScenarioMultipliers = bearScenario
    ? { revenueGrowthMultiplier: toNum(bearScenario.revenueGrowthMultiplier), costPressureAdjustment: toNum(bearScenario.costPressureAdjustment) }
    : { revenueGrowthMultiplier: 0.6, costPressureAdjustment: 1.5 };

  const bullMult: ScenarioMultipliers = bullScenario
    ? { revenueGrowthMultiplier: toNum(bullScenario.revenueGrowthMultiplier), costPressureAdjustment: toNum(bullScenario.costPressureAdjustment) }
    : { revenueGrowthMultiplier: 1.4, costPressureAdjustment: -0.5 };

  const scenarios = calculateScenarios(baseYearData, baseAssumptions, baseSynergies, fundingLineInputs, bearMult, bullMult);

  const bearReturns = calculateReturns(scenarios.bear, exitAssumptions, entryEquity, entryMultiple, totalDebt, totalFees, fundingLineInputs);
  const baseReturns = calculateReturns(scenarios.base, exitAssumptions, entryEquity, entryMultiple, totalDebt, totalFees, fundingLineInputs);
  const bullReturns = calculateReturns(scenarios.bull, exitAssumptions, entryEquity, entryMultiple, totalDebt, totalFees, fundingLineInputs);

  return {
    projections: scenarios,
    returns: { bear: bearReturns, base: baseReturns, bull: bullReturns },
  };
}, [baseYearData, activeAssumptions, vcData, fundingLineInputs, exitAssumptions, entryEquity, entryMultiple, totalDebt, totalFees]);
```

**2. Exit valuation breakdown per scenario:**

```tsx
const exitValuations = useMemo(() => {
  const holdYears = Math.min(exitAssumptions.holdPeriodYears, 5);

  const calc = (projections: ProjectedYear[], ret: ReturnMetrics) => {
    const exitYear = projections[holdYears - 1];
    if (!exitYear) return null;
    const exitEV = exitYear.ebitda * exitAssumptions.exitMultiple;
    const exitCosts = exitEV * exitAssumptions.exitCostPercent / 100;
    return {
      exitYearEbitda: exitYear.ebitda,
      exitEV,
      exitCosts,
      remainingDebt: exitEV - ret.exitEquity - exitCosts,
      exitEquity: ret.exitEquity,
      y5Revenue: exitYear.revenue,
      y5EbitdaMargin: exitYear.revenue > 0 ? (exitYear.ebitda / exitYear.revenue) * 100 : 0,
    };
  };

  return {
    bear: calc(scenarios.bear, returns.bear),
    base: calc(scenarios.base, returns.base),
    bull: calc(scenarios.bull, returns.bull),
  };
}, [scenarios, returns, exitAssumptions]);
```
