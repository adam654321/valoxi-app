# Prompt 3: Valuation Dashboard Tab & Impact Summary Bar

## Context

This is prompt 3 of 4 in the Value Creation Modeller redesign. Prompts 1 (zero-equity fix) and 2 (tab architecture) should already be applied. The 5-tab structure exists with a Dashboard placeholder. This prompt replaces that placeholder with a full single-screen valuation dashboard and adds a live impact summary bar.

After this prompt, the core "tweak left, see impact right, instantly" experience is live.

## 1. Create `ValuationDashboard.tsx`

Create: `client/src/components/value-creation/ValuationDashboard.tsx`

This is the default landing view for the Value Creation module. It must fit on one screen without scrolling (target max height ~700-800px on a standard 1080p display). It shows all key metrics at a glance with Bear/Base/Bull side by side.

### Props Interface

```typescript
interface ValuationDashboardProps {
  // Core data
  projections: ProjectedYear[];
  baseYearData: BaseYearData;
  baseYearLabel: string;
  
  // Returns & scenarios
  returnMetrics: ReturnMetrics | null;
  scenarioComparison: {
    projections: { bear: ProjectedYear[]; base: ProjectedYear[]; bull: ProjectedYear[] };
    returns: { bear: ReturnMetrics; base: ReturnMetrics; bull: ReturnMetrics };
  } | null;
  
  // Deal context
  exitAssumptions: ExitAssumptions;
  entryMultiple: number;
  entryEquity: number;
  
  // For impact tracking
  previousMetrics: ImpactMetrics | null;
  currentMetrics: ImpactMetrics | null;
}
```

### Layout Structure

The dashboard has 3 rows:

**Row 1: Hero Metric Cards (most important row)**

A responsive grid of metric cards showing the key decision metrics. Each card shows Bear/Base/Bull values side by side where scenario data is available.

Metrics to display:
- **IRR** — from `returnMetrics` and `scenarioComparison.returns`. Colour-coded: ≥25% green, ≥15% blue, ≥10% amber, <10% red. If unavailable show "—" not "N/A".
- **MOIC** — same sources, colour-coded: ≥3x green, ≥2x blue, ≥1.5x amber, <1.5x red.
- **Payback Period** — from `returnMetrics`. Show in years. If >hold period, show ">5yrs" in amber.
- **Y5 EBITDA** — from `projections` and `scenarioComparison.projections`. Always available.
- **Cumulative FCF** — sum of `projections[].freeCashFlow`. Always available.
- **Worst DSCR** — min of `projections[].dscr`. Colour-coded: ≥1.8 green, ≥1.4 blue, ≥1.0 amber, <1.0 red.

Card design:
```tsx
<div className="grid grid-cols-2 lg:grid-cols-3 xl:grid-cols-6 gap-3">
  {/* Each card */}
  <Card className="border-l-4 border-l-{color}">
    <CardContent className="py-3 px-4">
      <p className="text-xs text-muted-foreground">{metric name}</p>
      
      {/* If scenario data available, show all three inline */}
      {scenarioComparison ? (
        <div className="flex items-baseline gap-2 mt-1">
          <span className="text-[10px] text-red-600 font-mono">{bear value}</span>
          <span className="text-lg font-bold font-mono">{base value}</span>
          <span className="text-[10px] text-green-600 font-mono">{bull value}</span>
        </div>
      ) : (
        <p className="text-lg font-bold mt-0.5 font-mono">{base value only}</p>
      )}
    </CardContent>
  </Card>
</div>
```

The bear value is small text left, base value is large centre, bull value is small text right. This gives instant range visibility without toggling.

When `returnMetrics` is null (no equity/funding), only show Y5 EBITDA, Cumulative FCF, and Worst DSCR (3 cards instead of 6).

**Row 2: Value Bridge Chart (centre stage)**

This is the single most important visualisation in the module. It shows where returns come from: EBITDA growth, multiple expansion, debt paydown, cash distributions, less fees.

Pull the value bridge chart logic from `ReturnsAnalysisSection.tsx` and render it here at a larger size. If `returnMetrics` is null, show a compact empty state instead.

The chart should be a horizontal or vertical waterfall bar chart showing:
- Entry Equity (starting point)
- + EBITDA Growth Value
- + Multiple Expansion Value  
- + Debt Paydown Value
- + Cash Distributions
- − Fees & Costs
- = Total Return (endpoint)

Use `returnMetrics.ebitdaGrowthValue`, `returnMetrics.multipleExpansionValue`, `returnMetrics.debtPaydownValue`, `returnMetrics.cashDistributionsValue`, `returnMetrics.feesDeducted`.

If `scenarioComparison` is available, show three grouped bars (Bear/Base/Bull) for each waterfall step. If not, single bars for base case only.

Target height: ~250-300px.

**Row 3: Two compact panels side by side**

Left panel (~50% width): **Mini P&L Summary**

A compact table showing the base year vs Y5 projected values for key P&L lines:

| | Base Year | Y5 Projected | Change |
|---|---|---|---|
| Revenue | £X | £Y | +Z% |
| Gross Profit | £X | £Y | +Z% |
| EBITDA | £X | £Y | +Z% |
| EBITDA Margin | X% | Y% | +Zpp |
| Net Profit | £X | £Y | +Z% |

Use data from `baseYearData` and `projections[projections.length - 1]`. The "Change" column should be colour-coded green/red.

If `scenarioComparison` is available, add bear and bull Y5 columns. Keep it compact — only these 5 rows.

Right panel (~50% width): **Mini Scenario Summary**

Three compact cards (Bear/Base/Bull) showing:
- Exit EBITDA
- Exit EV  
- Exit Equity
- IRR
- MOIC

Use data from `scenarioComparison.returns` and calculated exit values. If `scenarioComparison` is null, show an empty state saying "Configure scenarios to see comparison."

Layout: three narrow cards in a row, coloured left-border (red/blue/green) matching the existing Bear/Base/Bull colour scheme.

Target height for Row 3: ~200-250px combined.

### Responsive Behaviour

- **xl (≥1280px):** All 6 hero cards in one row. Value bridge full width. Bottom two panels side by side.
- **lg (≥1024px):** 3 hero cards per row (2 rows). Rest same.
- **md and below:** 2 hero cards per row. Bottom panels stack vertically. Value bridge may need reduced height.

## 2. Create `ImpactSummaryBar.tsx`

Create: `client/src/components/value-creation/ImpactSummaryBar.tsx`

This component shows the "what just changed?" delta when assumptions are modified. It lives on the Dashboard tab only, positioned between Row 1 (hero cards) and Row 2 (value bridge).

### Types

```typescript
export interface ImpactMetrics {
  y5Ebitda: number;
  cumulativeFcf: number;
  irr: number | null;       // null when returnMetrics unavailable
  moic: number | null;       // null when returnMetrics unavailable
  worstDscr: number;
}

interface ImpactSummaryBarProps {
  current: ImpactMetrics | null;
  previous: ImpactMetrics | null;
}
```

### Display Logic

- If `previous` is null (first load, no change yet): **don't render anything** (return null). The hero cards already show current values.
- If `previous` exists and values differ from `current`: show the impact bar with deltas.
- Format: `EBITDA: £420K → £485K (+15.5%)  ·  IRR: 18.2% → 23.1%  ·  MOIC: 2.1x → 2.4x  ·  FCF: +£62K`
- Green text for positive changes in EBITDA/FCF/IRR/MOIC. Red for negative.
- For DSCR: green when moving AWAY from 1.0 (getting safer), red when moving TOWARD 1.0.
- Skip metrics where value is null in both current and previous (don't show "N/A → N/A").
- The bar should have a subtle entrance animation (opacity 0→1, slight translateY).

### Visual Design

```tsx
<div className="rounded-lg border bg-muted/30 border-l-4 border-l-primary px-4 py-2 flex items-center gap-4 overflow-x-auto animate-in fade-in slide-in-from-bottom-1 duration-300">
  {/* Each metric delta */}
  <div className="flex items-center gap-1.5 whitespace-nowrap">
    <span className="text-xs text-muted-foreground">EBITDA</span>
    <span className="text-xs font-mono text-muted-foreground">{formatCurrency(previous.y5Ebitda)}</span>
    <span className="text-xs text-muted-foreground">→</span>
    <span className="text-xs font-mono font-semibold">{formatCurrency(current.y5Ebitda)}</span>
    <span className={`text-[10px] font-mono ${delta >= 0 ? 'text-green-600' : 'text-red-600'}`}>
      ({delta >= 0 ? '+' : ''}{deltaPercent.toFixed(1)}%)
    </span>
  </div>
  
  {/* Separator dot between metrics */}
  <span className="text-muted-foreground/30">·</span>
  
  {/* ... more metrics ... */}
</div>
```

## 3. Impact Tracking in `ValueCreationModeller.tsx`

Add the state and logic to track metric deltas in the main component.

### Import the ImpactMetrics type

```typescript
import type { ImpactMetrics } from '@/components/value-creation/ImpactSummaryBar';
```

### Add State

```typescript
const prevMetricsRef = useRef<ImpactMetrics | null>(null);
const [displayPrevious, setDisplayPrevious] = useState<ImpactMetrics | null>(null);
const fadeTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
```

### Build Current Metrics

```typescript
const currentImpactMetrics = useMemo<ImpactMetrics | null>(() => {
  if (!kpis) return null;
  return {
    y5Ebitda: kpis.y5Ebitda,
    cumulativeFcf: kpis.totalCashGenerated,
    irr: returnMetrics?.irr ?? null,
    moic: returnMetrics?.moic ?? null,
    worstDscr: kpis.worstDscr,
  };
}, [kpis, returnMetrics]);
```

### Track Changes

```typescript
useEffect(() => {
  if (!currentImpactMetrics) return;

  if (prevMetricsRef.current) {
    const changed = JSON.stringify(currentImpactMetrics) !== JSON.stringify(prevMetricsRef.current);
    if (changed) {
      setDisplayPrevious({ ...prevMetricsRef.current });
      
      // Clear previous deltas timer if exists
      if (fadeTimerRef.current) clearTimeout(fadeTimerRef.current);
      
      // Fade out deltas after 8 seconds
      fadeTimerRef.current = setTimeout(() => {
        setDisplayPrevious(null);
      }, 8000);
    }
  }
  
  // Always update the ref to latest
  prevMetricsRef.current = { ...currentImpactMetrics };
}, [currentImpactMetrics]);

// Cleanup timer on unmount
useEffect(() => {
  return () => {
    if (fadeTimerRef.current) clearTimeout(fadeTimerRef.current);
  };
}, []);
```
