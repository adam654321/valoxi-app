BUILD PROMPT — Deal documents upload dialog helper text (#108)

CONTEXT
The internal "Upload New Document" dialog on the target company Documents
tab currently shows no explanation of which files trigger AI extraction
and no indication of the 10 MB max file size. Users do not learn the limit
until upload fails. They also conflate the 10 AI-analyzable types with
arbitrary deal paperwork (a usability trap, separately tracked as #107).

This change adds two pieces of UI copy. Pure UI copy, single file touched.

The file is client/src/components/document-management.tsx, rendered on the
target company detail page. It is the BUYER-side dialog. The SELLER-side
upload UI (client/src/pages/PortalPage.tsx, route /portal/:token) is a
different component and stays untouched. This separation is V-checked.

DialogDescription is already imported on line 11 of the file. No import
change needed.

The 10 MB limit is enforced server-side at
server/routes/documents-files.routes.ts line 17:
  multer({ ..., limits: { fileSize: 10 * 1024 * 1024 } })
The frontend hint is purely informational. The code comment in this build
points at that source of truth.
