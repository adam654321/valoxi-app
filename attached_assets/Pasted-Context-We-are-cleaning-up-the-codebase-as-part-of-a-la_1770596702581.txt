Context
We are cleaning up the codebase as part of a larger project to build a Deal Modeller feature. The application is an M&A CRM platform that helps buyers evaluate and structure acquisitions of target companies.
The platform originally had a three-stage AI analysis pipeline:

Stage 1 Analysis — An initial screening/summary using Gemini AI against uploaded company documents
Detailed Analysis — A deeper dive analysis
Expert Analysis — A multi-expert engine (QoE, Valuation, Deal Structure, Financial, Operational, Risk, Sector) that produces structured JSON outputs

The Expert Analysis engine has now fully replaced both Stage 1 and Detailed Analysis. Those features are being removed. We are also removing the standalone Valuation page as that functionality will be absorbed into the new Deal Modeller.
This is the first step of the cleanup. Before we remove anything, we need to understand all the dependencies.
