ADJUSTMENT 1: Repository — add a markActive method.

FILE 5 (EDIT): server/repositories/nylas.repository.ts

  Add this method to the existing nylasRepository object,
  immediately after markRevoked:

    async markActive(grantId: string) {
      await db.update(nylasGrants).set({
        status: 'active',
        lastErrorAt: null,
        lastErrorMessage: null,
        updatedAt: new Date(),
      }).where(eq(nylasGrants.grantId, grantId));
    },

  Rationale: a freshly re-authed grant must end up in 'active' state.
  The assess's markRevoked-only approach leaves the grant in 'revoked'
  which is worse than the no-handling case. Also clears
  lastErrorAt/Message so a previously broken grant comes back clean.
