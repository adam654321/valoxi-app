Props:
typescriptinterface AdjustmentsSectionProps {
  modelId: number;
  adjustments: DealModelAdjustment[];
  calculations: CalculationResult | null;
  isLocked: boolean;
  onDataChange: () => void;  // Callback to invalidate/refetch the model after mutations
}
Mutations needed (define these in the component using useMutation + apiRequest):

Accept/reject adjustment: PUT /api/v2/deal-models/${modelId}/adjustments/${adjId} with body { status: 'accepted' | 'rejected' }
Modify adjustment: Same endpoint with body { status: 'modified', userOverrideAmount: number, userOverrideReason: string }
Bulk accept all: PUT /api/v2/deal-models/${modelId}/adjustments/bulk with body { updates: [{ id, status: 'accepted' }...] }
Add custom adjustment: POST /api/v2/deal-models/${modelId}/adjustments with body containing the adjustment fields
Delete adjustment: DELETE /api/v2/deal-models/${modelId}/adjustments/${adjId} (only for manual/custom adjustments)

All mutations should call onDataChange() on success to trigger a refetch of the model data.
