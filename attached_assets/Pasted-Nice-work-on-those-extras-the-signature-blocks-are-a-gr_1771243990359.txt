PROMPT 4: Token Auto-Extension on Deal Events
Context for Replit:
Portal tokens have an expiresAt field that defaults to 30 days from creation. Currently there's no automatic extension. We need the token expiry to automatically reset to a fresh 30 days whenever key deal events happen, so the portal doesn't expire mid-deal.
The three trigger points are all in server/services/deal-document.service.ts:

The sendDocument() method — fires when an offer letter or HoT is sent
The recordResponse() method — fires when the seller accepts a document (specifically when HoT is accepted, which activates Stage 2)

Prompt:
Add automatic portal token expiry extension when key deal events occur. This prevents portal links from expiring during active deal progression.

STEP 1 — Create a new file: server/services/portal-token.service.ts

import { db } from '../db';
import { portalAccessTokens, portalActivityLog } from '@shared/schema/portal';
import { eq, and, sql } from 'drizzle-orm';

export async function extendPortalTokenForCompany(
  targetCompanyId: number, 
  reason: string,
  daysToExtend: number = 30
): Promise<void> {
  try {
    // Find all active portal tokens for this target company
    const tokens = await db.select()
      .from(portalAccessTokens)
      .where(
        and(
          eq(portalAccessTokens.targetCompanyId, targetCompanyId),
          eq(portalAccessTokens.isActive, true)
        )
      );

    if (tokens.length === 0) {
      console.log(`[PORTAL_TOKEN] No active tokens found for company ${targetCompanyId}, skipping extension`);
      return;
    }

    // Extend each active token
    for (const token of tokens) {
      await db.update(portalAccessTokens)
        .set({
          expiresAt: sql`NOW() + INTERVAL '${sql.raw(String(daysToExtend))} days'`,
        })
        .where(eq(portalAccessTokens.id, token.id));

      // Log the extension in the activity log
      await db.insert(portalActivityLog).values({
        portalTokenId: token.id,
        targetContactId: token.targetContactId,
        activityType: 'token_auto_extended',
        activityDescription: `Token automatically extended by ${daysToExtend} days. Reason: ${reason}`,
      });

      console.log(`[PORTAL_TOKEN] Extended token ${token.id} by ${daysToExtend} days — ${reason}`);
    }
  } catch (err) {
    console.error('[PORTAL_TOKEN] Failed to extend token:', err);
    // Don't throw — token extension failure should never break the main operation
  }
}
