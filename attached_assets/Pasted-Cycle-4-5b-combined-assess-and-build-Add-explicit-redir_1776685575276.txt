1b. Replace the three-line sendAdminSignInLink call with four lines that construct an explicit redirect URL:
From:
const emailResult = await emailApiService.sendAdminSignInLink({
  to: user.email,
  firstName: user.firstName || 'there',
  signInUrl: signInToken.url,
});
To:
const signInUrlWithRedirect = new URL(signInToken.url);
signInUrlWithRedirect.searchParams.set('redirect_url', config.baseUrl);
const emailResult = await emailApiService.sendAdminSignInLink({
  to: user.email,
  firstName: user.firstName || 'there',
  signInUrl: signInUrlWithRedirect.toString(),
});
This appends a redirect_url query parameter to Clerk's sign-in ticket URL. The config.baseUrl resolves to:

https://app.valoxi.ai on prod
The Replit dev URL on dev
Based on APP_URL, REPLIT_DOMAINS, REPLIT_DEV_DOMAIN fallback chain in server/config.ts
