Context
Section 2 (Adjustments UI) was just built and works correctly. However, we need to enhance it so adjustments can be applied to specific years rather than just as a flat amount. This is critical for M&A accuracy — a one-off item like a COVID grant in 2020 should only reduce that year's EBITDA, not spread across all years in the average.
The infrastructure already supports this: deal_model_adjustments.amountsByYear is a JSON field (e.g. {"2021": 45000, "2022": 48000}), and calculateAdjustedEbitda in the shared calculator already checks amountsByYear[year] before falling back to the flat amount. This is a UI-only enhancement.
