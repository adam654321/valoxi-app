Root cause — three problems

authService.register() sets isCompanyAdmin: true but never sets userRole: 'company_admin' — so the user gets is_company_admin = true but user_role = 'analyst' (the schema default). The RBAC check uses isCompanyAdmin which works, but the role label is wrong.
onboarding/complete writes the free-text job title directly to user_role, overwriting whatever was there and breaking RBAC completely.
There's nowhere to store the job title separately. The schema has no jobTitle field — it needs adding.
