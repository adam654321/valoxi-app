1. Create server/repositories/deal-model.repository.ts
Data access methods. Use the db instance from server/db.ts and Drizzle query patterns. Methods needed:

create(data) — Insert a deal model, return the created record
getById(id) — Get a single deal model by ID
getByIdWithDetails(id) — Get a deal model with its adjustments and funding lines (use Drizzle with relations or separate queries)
listByCompany(targetCompanyId) — List all deal models for a target company, ordered by updatedAt desc
update(id, data) — Partial update of deal model fields, set updatedAt to now
delete(id) — Delete a deal model and cascade to its adjustments and funding lines
duplicate(id, newName, userId) — Copy a deal model and all its adjustments/funding lines, set parentModelId to the source, increment version, reset status to 'draft'
lock(id) — Set isLocked = true and status = 'sent'

Adjustment methods:

createAdjustment(data) — Insert a single adjustment
createAdjustments(data[]) — Bulk insert adjustments
updateAdjustment(id, data) — Update an adjustment (for accept/reject/modify)
bulkUpdateAdjustments(dealModelId, updates[]) — Bulk accept/reject: each update has { id, status, userOverrideAmount?, userOverrideReason? }
getAdjustmentsByModelId(dealModelId) — List all adjustments for a model
deleteAdjustment(id) — Delete a single adjustment

Funding line methods:

createFundingLine(data) — Insert a funding line
createFundingLines(data[]) — Bulk insert funding lines
updateFundingLine(id, data) — Update a funding line
getFundingLinesByModelId(dealModelId) — List all funding lines for a model
deleteFundingLine(id) — Delete a single funding line

2. Create server/services/deal-model.service.ts
Business logic layer. Import the repository, mapping service, and calculation engine. Follow the pattern of pipeline.service.ts — validate inputs, call repository, handle errors.
Key methods:

createModel(targetCompanyId, createdBy, userCompanyId, modelName?) — Delegates to the mapping service's createDealModelFromExperts, then runs the calculation engine and saves the calculated values (enterpriseValue, offerPrice, totalFees, totalFundingRequired) back to the model. Returns the full model with adjustments and funding lines.
getModel(id, userCompanyId) — Fetch model with details. Verify the model belongs to a target company owned by the user's company (security check). Run calculations fresh and return alongside the stored data.
listModels(targetCompanyId, userCompanyId) — List all models for a company. Verify ownership.
updateModel(id, userCompanyId, updates) — Validate the model isn't locked. Update fields. Re-run calculations and save computed values.
updateAdjustment(modelId, adjustmentId, userCompanyId, updates) — Validate model isn't locked. Update the adjustment. Re-run calculations on the parent model and save.
bulkUpdateAdjustments(modelId, userCompanyId, updates[]) — Same but bulk. Re-run calculations once after all updates.
addFundingLine(modelId, userCompanyId, data) — Validate model isn't locked. Create funding line. Re-run calculations.
updateFundingLine(modelId, lineId, userCompanyId, data) — Same pattern for update.
deleteFundingLine(modelId, lineId, userCompanyId) — Same pattern for delete.
duplicateModel(id, userCompanyId, newName?) — Delegates to repository duplicate. Returns the new model.
lockModel(id, userCompanyId) — Delegates to repository lock.
addCustomAdjustment(modelId, userCompanyId, data) — For user-created adjustments (not from experts). Set sourceExpert = null, status = 'accepted'.
recalculate(modelId) — Internal method. Fetches the model with adjustments and funding lines, fetches reported EBITDA from income statements, runs calculateFullDealModel, saves computed values back. This is called after every mutation.

Export as singleton: export const dealModelService = new DealModelService();
3. Create server/routes/deal-model.routes.ts
API routes following the existing Express router pattern. Use sendSuccess, sendCreated, sendError from utils. Extract userId and userCompanyId from req.session.
POST   /create/:companyId         — Create model from expert data
GET    /company/:companyId        — List all models for a company
GET    /:id                       — Get single model with adjustments + funding
PUT    /:id                       — Update model parameters
POST   /:id/adjustments           — Add custom adjustment
PUT    /:id/adjustments/:adjId    — Update single adjustment (accept/reject/modify)
PUT    /:id/adjustments/bulk      — Bulk update adjustments
DELETE /:id/adjustments/:adjId    — Delete custom adjustment
POST   /:id/funding-lines         — Add funding line
PUT    /:id/funding-lines/:lineId — Update funding line
DELETE /:id/funding-lines/:lineId — Delete funding line
POST   /:id/lock                  — Lock model
POST   /:id/duplicate             — Duplicate model
GET    /:id/calculate             — Re-run calculations and return results (no save)
Important: The PUT /:id/adjustments/bulk route must be defined BEFORE PUT /:id/adjustments/:adjId — otherwise Express will match "bulk" as an :adjId parameter.
4. Register the routes in server/routes/index.ts
Import dealModelRoutes and mount at:
typescriptapp.use('/api/v2/deal-models', isAuthenticated, dealModelRoutes);
