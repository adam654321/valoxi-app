Plan: Modern Sidebar Navigation
Goal: Transform the application layout from a traditional top-navbar to a modern, collapsible sidebar navigation system. This improves scalability (Vertical > Horizontal for many items) and aligns with modern SaaS aesthetics.

🧠 Design Principles (UX Psychology)
Serial Position Effect: Key items (Dashboard, Pipeline) at top; Admin/Settings at bottom.
Miller's Law (Chunking): Group navigation items into logical sections (Main, Analytics, Admin) rather than one long list.
Hick's Law: Simplify choices. Use icons + text. Allow collapsing the sidebar to reduce visual noise.
Fitts' Law: Sidebar items are easier to hit (infinite left edge) than top nav items.
🏗️ Proposed Architecture
1. New Component Structure (client/src/components/layout/)
Sidebar.tsx: The main left-hand navigation column.
State: isCollapsed (boolean) - toggled by a button.
Content: Logo area, grouped nav links, user profile at bottom.
Header.tsx: Top bar (much thinner than before).
Content: Breadcrumbs, Global Search, Notifications, "Add Target" Action.
MainLayout.tsx: The wrapper combining Sidebar + Header + Page Content.
CSS Grid or Flexbox layout: [Sidebar] [Header + Content].
