Add a new method to the PortalRequirementsRepository class. Naming and signature exactly:

  async areAllMandatorySubmitted(targetCompanyId: number, stage: number): Promise<boolean>

Behaviour:
- SELECT isMandatory and requirementStatus from companyDocumentRequirements
  WHERE targetCompanyId = $1 AND collectionStage = $2.
- Filter rows to mandatory: r.isMandatory !== false  (so true and null both count as mandatory).
- If the filtered mandatory array is empty, return false. This deliberately treats "no requirements initialised" as non-terminal so we do not auto-complete schedules for companies whose requirements have not been set up.
- Otherwise return mandatory.every(r => r.requirementStatus === 'submitted' || r.requirementStatus === 'approved'). This matches the convention already used in getRequirementCountByStage.
