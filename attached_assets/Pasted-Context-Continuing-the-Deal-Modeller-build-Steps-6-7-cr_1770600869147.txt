```
**Then implement these functions:**

**1. `toNum(value)` — Helper to safely convert string/number/null to number:**
Drizzle decimal columns return strings. This helper should handle `string | number | null | undefined` → `number`, defaulting to 0.

**2. `calculateAdjustedEbitda(reportedEbitdaByYear, adjustments, averagingYears)` → `{ adjustedEbitdaByYear, averageAdjustedEbitda }`**
```
reportedEbitdaByYear: Record<string, number>  // e.g. {"2021": 500000, "2022": 550000, "2023": 600000}
adjustments: AdjustmentInput[]
averagingYears: number (2-5)
```

For each year:
- Start with reported EBITDA for that year
- Add amounts from accepted/modified add_backs (use `userOverrideAmount` if status is 'modified', otherwise `amount`). If `amountsByYear` has a value for that year, use it; otherwise use the flat `amount`
- Subtract amounts from accepted/modified deductions (same logic)

Then average the last N years (where N = `averagingYears`), sorted by year descending, taking the most recent N.

**3. `calculateOfferPrice(averageAdjustedEbitda, model)` → `{ enterpriseValue, offerPrice }`**
```
enterpriseValue = averageAdjustedEbitda × ebitdaMultiple

offerPrice = enterpriseValue
  + plusExcessCash
  - minusPrimaryDebt
  - minusOtherDebt
  - minusCorpTaxDue
  - minusWorkingCapitalAdj
  + plusPropertyValue
  + SUM(otherAdjustments[].amount)
```

**4. `calculateFees(offerPrice, model)` → fee breakdown + totalFees + totalFundingRequired**

Each standard fee = `offerPrice × percent / 100`. Custom fees can have either a percent (calculated from offer price) or a fixed amount. `totalFundingRequired = offerPrice + totalFees`.

**5. `calculateFundingStack(fundingLines)` → per-line calculations + totals**

For each active funding line:
- `availableAmount = assetBaseValue × ltvPercent / 100` (for asset-based lines where both values exist)
- `monthlyRepayment` = PMT calculation: `PMT(rate/12, termMonths, amountUsed)`. The PMT formula is: `P × r × (1+r)^n / ((1+r)^n - 1)` where P = principal (amountUsed), r = monthly rate (interestRate/100/12), n = termMonths. If rate is 0 or term is 0/null, monthly repayment = amountUsed / termMonths (or 0 if no term).
- `annualRepayment = monthlyRepayment × 12`
- `arrangementFee = amountUsed × arrangementFeePercent / 100`

For revolving facilities (termMonths = 1 or null): monthly repayment = interest only = `amountUsed × interestRate / 100 / 12`

`totalFunded = SUM(amountUsed for all active lines)`
`fundingGap = totalFundingRequired - totalFunded`

**6. `calculatePaymentCover(averageAdjustedEbitda, totalAnnualDebtService)` → `{ paymentCoverRatio, paymentCoverRating }`**
```
paymentCoverRatio = averageAdjustedEbitda / totalAnnualDebtService

Ratings:
  > 2.0  → 'strong'
  1.5-2.0 → 'adequate'  
  1.0-1.5 → 'tight'
  < 1.0   → 'unfundable'
  no debt → 'no_debt'
7. calculateFullDealModel(reportedEbitdaByYear, adjustments, fundingLines, model) → CalculationResult
Orchestrator that calls all the above in sequence and returns the complete result. This is the main function that both client and server will call.
