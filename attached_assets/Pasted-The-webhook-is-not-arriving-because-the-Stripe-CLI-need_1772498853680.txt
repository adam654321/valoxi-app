The webhook is not arriving because the Stripe CLI needs to be running to forward events to the Replit dev environment. We also need a session_id fallback on the billing page so activation works even if the webhook is delayed.
Fix 1 — Session ID fallback on the billing page:
In client/src/pages/billing.tsx, read the session_id query parameter from the URL after Stripe checkout redirect. If present, call a new server endpoint to verify and activate the session directly, then invalidate the subscription query so the page refreshes with the correct plan.
Add POST /api/v2/billing/verify-session to server/routes/billing.routes.ts:

Requires isAuthenticated and validateCsrfToken
Accepts { sessionId: string } in the body
Calls stripe.checkout.sessions.retrieve(sessionId) to get the session
Verifies session.metadata.userCompanyId matches req.session.userCompanyId — reject if not (security check)
If session.payment_status === 'paid' and no active subscription exists yet for this company, calls billingService.activateSubscription with the session data
Returns { success: true, planKey, status } on success
Returns { success: false, reason: string } if already activated or session not paid

In the billing page:

On mount, check const sessionId = new URLSearchParams(window.location.search).get('session_id')
If present, call POST /api/v2/billing/verify-session with the sessionId
On success, call queryClient.invalidateQueries(['/api/v2/billing/subscription']) to refresh the plan display
Remove the session_id from the URL after processing using window.history.replaceState
Show a toast: "Payment successful — your plan has been activated"
Show a loading spinner on the billing page while verification is in flight

Fix 2 — Verify Stripe CLI is correctly configured:
Check server/config.ts — confirm stripe.webhookSecret reads from process.env.STRIPE_WEBHOOK_SECRET. Log a clear warning on server startup if either STRIPE_SECRET_KEY or STRIPE_WEBHOOK_SECRET are missing:
[billing] WARNING: STRIPE_SECRET_KEY not set — billing features will not work
[billing] WARNING: STRIPE_WEBHOOK_SECRET not set — webhooks will not be verified
