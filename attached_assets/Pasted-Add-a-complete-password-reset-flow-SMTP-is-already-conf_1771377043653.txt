Add a complete password reset flow. SMTP is already configured and working 
— the existing email service in server/services/email.service.ts and 
server/email.ts should be used as the pattern.

1. SCHEMA
Add a password_reset_tokens table to shared/schema/core.ts with columns:
- id: serial primary key
- userId: integer, foreign key to users.id, not null
- token: varchar(64) not null, unique
- expiresAt: timestamp not null
- usedAt: timestamp nullable
- createdAt: timestamp default now() not null

Export the table and its insert/select types from the barrel file.
Run db:push to apply.

2. BACKEND — Repository
Create server/repositories/password-reset.repository.ts with methods:
- createToken(userId): generates a cryptographically random 64-char hex token 
  using randomBytes(32).toString('hex'), sets expiresAt to 1 hour from now, 
  inserts and returns the row
- getValidToken(token): finds the token where usedAt is null and expiresAt is 
  in the future, returns undefined if not found
- markUsed(id): sets usedAt = now() on the token row
- deleteExpiredTokens(): deletes all rows where expiresAt < now() (for cleanup)
- deleteUserTokens(userId): deletes all existing reset tokens for a user before 
  creating a new one (prevents multiple active tokens per user)

3. BACKEND — Service
Create server/services/password-reset.service.ts with:

requestReset(email: string, baseUrl: string): Promise<void>
- Look up user by email via usersRepository.getByEmail()
- If user not found, return silently (never reveal whether email exists)
- Call deleteUserTokens(userId) to invalidate any existing tokens
- Call createToken(userId)
- Send an email using the existing email service with:
  Subject: 'Reset your password — M&A Platform'
  Body: A clean HTML email with the reset link: 
  {baseUrl}/reset-password?token={token}
  Link expires in 1 hour.
  If no account exists for this email, no email is sent (silent fail is 
  intentional for security)

validateToken(token: string): Promise<{ valid: boolean; userId?: number }>
- Calls getValidToken(token)
- Returns { valid: false } if not found
- Returns { valid: true, userId: row.userId } if found

resetPassword(token: string, newPassword: string): Promise<void>
- Calls getValidToken(token) — throws BadRequestError if invalid or expired
- Validates newPassword is at least 8 characters — throws BadRequestError if not
- Hashes the new password with bcrypt (10 rounds)
- Updates the user's passwordHash in the database
- Calls markUsed(tokenId) to invalidate the token
- Destroys any active sessions for this user if possible

4. BACKEND — Routes
Add three new public routes to server/routes/auth.routes.ts 
(no isAuthenticated required):

POST /api/v2/auth/forgot-password
- Body: { email: string } validated with Zod
- Calls passwordResetService.requestReset(email, baseUrl)
- Always returns 200 with { message: 'If an account exists for that email, 
  a reset link has been sent.' } regardless of whether email was found

GET /api/v2/auth/reset-password/validate
- Query param: token
- Calls passwordResetService.validateToken(token)
- Returns { valid: true } or { valid: false }

POST /api/v2/auth/reset-password
- Body: { token: string, password: string, confirmPassword: string }
- Validates password === confirmPassword and password min 8 chars with Zod
- Calls passwordResetService.resetPassword(token, password)
- Returns { message: 'Password reset successfully. You can now log in.' }

5. ADMIN OVERRIDE — Force Reset
Add a new route to server/routes/admin.routes.ts:

POST /api/v2/admin/users/:id/reset-password
- Body: { newPassword: string } min 8 chars
- Admin only (already behind isAuthenticated + isSystemAdmin)
- Directly hashes and updates the user's passwordHash without any token flow
- Returns { message: 'Password updated successfully' }

Add a "Reset Password" button to the users table in 
client/src/pages/admin/users.tsx that opens a small dialog with a new 
password field and confirm field. On submit it calls the admin reset endpoint. 
Show a success toast on completion.
