STEP 2 — Apply the DDL directly via psql / db connection
Run the following SQL in a single transaction:

BEGIN;

ALTER TABLE user_invitations
  ADD COLUMN first_name varchar(100),
  ADD COLUMN last_name varchar(100),
  ADD COLUMN job_title varchar(100);

CREATE INDEX users_email_lower_idx ON users (LOWER(email));

COMMIT;

All three new columns are deliberately added as nullable for now. Prompt
2 will populate them through the createInvitation flow, then ALTER
first_name and last_name to NOT NULL at the end of Prompt 2 once we have
verified every code path is providing them. job_title stays nullable
permanently (it is optional at invite time).

The index is plain (non-unique) btree on the LOWER(email) expression, to
speed up the orphan-match query in webhooks.routes.ts line 57:
  WHERE LOWER(users.email) = LOWER(?)
