Context
We're building the Deal Modeller feature. Steps 1-5 cleaned up the codebase — legacy features removed, files reorganised. Now we're creating the data layer. This is the first build step.
The codebase uses Drizzle ORM with PostgreSQL (Neon serverless). Schema is modular — split into domain files under shared/schema/ with a barrel export. Each schema file follows the same pattern: table definitions → insert schemas (via createInsertSchema from drizzle-zod) → type exports. Relations are defined separately in shared/schema/relations.ts.
