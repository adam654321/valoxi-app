Replit Prompt 3: Add Document Viewing to Stage 2 DD
## Context

In the Stage 2 Due Diligence document collection feature, documents that are linked (by the buyer) or uploaded (by the seller) against DD requirements cannot be viewed. Both the external portal component (`client/src/components/portal/DdCollection.tsx`) and the internal buyer component (`client/src/components/target-company/DueDiligenceTab.tsx`) only show filenames as plain text — there is no way to click through and view the actual document content.

The codebase already has a `DocumentViewer` component at `client/src/components/document-viewer/DocumentViewer.tsx` that handles multi-format document viewing (PDF, images, Office documents). It is already used in the Stage 1 portal view (`enhanced-portal-display.tsx`) and in the internal document management view.

## Task

### 1. Portal Side — `client/src/components/portal/DdCollection.tsx`

**Add document viewing capability to linked/uploaded documents in the DD requirements list.**

a) **Import the DocumentViewer component:**
```typescript
import { DocumentViewer } from '@/components/document-viewer';

b) Add state for the document viewer:

const [viewingDocument, setViewingDocument] = useState<any | null>(null);
const [showViewer, setShowViewer] = useState(false);

c) Make document filenames clickable:

In the "Already held" section (buyer_linked documents, around lines 390-397), and the "Your uploads" section (seller_uploaded documents, around lines 405-420), make each document filename a clickable button/link that opens the document viewer.

For buyer_linked documents, the LinkedDocument has a documentId field. Use this to construct a document object that the DocumentViewer can accept. The viewer needs at minimum: { id, originalFilename, fileType, fileSize }.

For seller_uploaded documents, the LinkedDocument has an externalSubmissionId field. The document was also created in the documents table when submitted, so there should be a documentId on the linked doc record as well. Use whichever ID is available.

d) Add a View button or make the filename clickable:

Change the filename <span> elements to clickable elements (either <button> with appropriate styling, or add a small Eye icon button next to each filename)
On click, set the viewing document and open the viewer
Style the filename with cursor-pointer hover:underline hover:text-blue-600 or similar to indicate it's clickable
e) Render the DocumentViewer at the bottom of the component (before the closing </Card>):

<DocumentViewer
  document={viewingDocument}
  isOpen={showViewer}
  onClose={() => { setShowViewer(false); setViewingDocument(null); }}
  onDownload={(docId, filename) => {
    window.open(`/api/v2/public/documents/${docId}/download`, '_blank');
  }}
  publicFileBaseUrl="/api/v2/public/documents"
  hideAnalysis={true}
/>

Note: Pass hideAnalysis={true} since this is the portal view (same as we did for Stage 1).
