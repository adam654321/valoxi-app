SCOPE: READ ONLY. SELECT only. No row modifications.

GOAL: Check timings on the most recent expert pipeline run for Aithon 
Solutions to compare against the historical baseline established earlier 
today, and specifically check whether the QoE timeout change (120s) 
materially affected QoE wall time on this run.

TASKS

1. Find the target_company_id for Aithon Solutions
   SELECT id, company_name, created_at 
   FROM target_companies 
   WHERE company_name ILIKE '%aithon%';
   
   Report the id and confirm there's only one match.

2. Most recent run per expert for that target
   For the target_company_id from task 1:
   
   SELECT 
     expert_type,
     status,
     processing_time AS processing_ms,
     ROUND(processing_time::numeric / 1000, 1) AS processing_seconds,
     created_at,
     updated_at,
     EXTRACT(EPOCH FROM (updated_at - created_at)) AS wall_seconds,
     usage_metadata
   FROM expert_analysis_results
   WHERE target_company_id = <id from task 1>
   ORDER BY created_at DESC
   LIMIT 20;
   
   Report all 8 Stage 2 expert rows from the most recent run plus the 
   data_quality and screening rows. If multiple historical runs exist, 
   include only the most recent set (group by created_at within a 30 
   minute window).

3. Total wall time for the most recent run
   For the most recent set of 8 Stage 2 experts only:
   
   SELECT 
     COUNT(*) AS expert_count,
     SUM(processing_time) AS sum_processing_ms,
     ROUND(SUM(processing_time)::numeric / 1000, 1) AS sum_seconds,
     MIN(created_at) AS run_start,
     MAX(updated_at) AS run_end,
     EXTRACT(EPOCH FROM (MAX(updated_at) - MIN(created_at))) AS true_wall_seconds
   FROM expert_analysis_results
   WHERE target_company_id = <id>
     AND created_at >= (
       SELECT MAX(created_at) - INTERVAL '30 minutes' 
       FROM expert_analysis_results 
       WHERE target_company_id = <id>
     );

4. Document analysis timing for this target
   SELECT 
     COUNT(*) AS doc_count,
     ROUND(AVG(processing_time)::numeric, 0) AS avg_doc_ms,
     SUM(processing_time) AS sum_doc_ms,
     ROUND(SUM(processing_time)::numeric / 1000, 1) AS sum_doc_seconds,
     MIN(created_at) AS earliest_doc,
     MAX(updated_at) AS latest_doc
   FROM document_analysis_results
   WHERE target_company_id = <id>;

5. Stage 1 timing
   SELECT 
     processing_time,
     detailed_analysis_processing_time,
     created_at,
     completed_at
   FROM stage1_analysis_events
   WHERE target_company_id = <id>
   ORDER BY created_at DESC
   LIMIT 5;

OUTPUT
Markdown report, one section per task, raw query output included. No 
interpretation needed.
