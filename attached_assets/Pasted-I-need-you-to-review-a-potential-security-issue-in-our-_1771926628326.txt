I need you to review a potential security issue in our [server/middleware/auth.ts](cci:7://file:///c:/Users/AdamAuty/Downloads/MandA-Internal-Google-Brain%20%287%29/MandA-Internal-Google-Brain/server/middleware/auth.ts:0:0-0:0) file, specifically the [isAuthenticated](cci:1://file:///c:/Users/AdamAuty/Downloads/MandA-Internal-Google-Brain%20%287%29/MandA-Internal-Google-Brain/server/middleware/auth.ts:7:0-28:1) middleware.

Currently, the middleware looks like this:

\`\`\`typescript
export async function isAuthenticated(req: Request, res: Response, next: NextFunction) {
  if (!req.session.userId) {
    return res.status(401).json({ message: "Unauthorized" });
  }
  next();
}
\`\`\`

**The Problem:**
It only checks if `req.session.userId` exists. It *does not* check if that user actually still exists in our database. If an admin deletes a user or suspends their account, but their session cookie is still valid, they will still be able to access protected routes because this middleware only checks the session object.

**Proposed Solution:**
I believe we need to query the database using Drizzle inside this middleware to verify the user record still exists. If the user doesn't exist, we should destroy the stale session and return a 401.

Here is the fix I am proposing:

\`\`\`typescript
export async function isAuthenticated(req: Request, res: Response, next: NextFunction) {
  if (!req.session.userId) {
    return res.status(401).json({ message: "Unauthorized" });
  }

  try {
    const [user] = await db.select({ id: users.id }).from(users).where(eq(users.id, req.session.userId));

    if (!user) {
      // If user doesn't exist but has a session, destroy the stale session
      if (req.session.destroy) {
        req.session.destroy(() => {});
      }
      return res.status(401).json({ message: "Unauthorized: User not found" });
    }

    next();
  } catch (error) {
    console.error('Error verifying user session:', error);
    return res.status(500).json({ message: "Internal server error during authentication" });
  }
}
\`\`\`
