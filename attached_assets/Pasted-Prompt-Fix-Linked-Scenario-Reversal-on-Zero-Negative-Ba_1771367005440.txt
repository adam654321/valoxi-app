Prompt: Fix Linked Scenario Reversal on Zero/Negative Base Growth
There's a critical bug in the linked scenario system. When base revenue growth is 0% or negative, Bear and Bull scenarios invert — Bear becomes the optimistic case and Bull becomes pessimistic. At 0% base, there's no spread at all.
Root cause: The offsets are being applied multiplicatively (e.g. baseGrowth * (1 - range/100)) instead of additively (e.g. baseGrowth - range). Multiplying a negative number by a larger factor makes it MORE negative, which flips the bear/bull relationship.
The fix: In calculateLinkedScenarios (in shared/calculators/value-creation.calc.ts), ensure ALL offsets are additive in percentage points, not multiplicative. The range value IS the offset — it gets added to or subtracted from the base value directly.
The correct formulas (as specified in the original prompt):
typescript// Revenue: full range as pp offset
const bearRevenueGrowth = baseRevenueGrowth - range;    // e.g. -5% - 30 = -35%
const bullRevenueGrowth = baseRevenueGrowth + range;    // e.g. -5% + 30 = +25%

// CoS: half range, inverse direction (bear = costs rise, bull = costs fall)
const bearCosGrowth = baseCosGrowth + (range * 0.5);    // e.g. 3.5% + 15 = 18.5%
const bullCosGrowth = baseCosGrowth - (range * 0.5);    // e.g. 3.5% - 15 = -11.5%

// Overheads: slight adjustment at 20% of range
const bearOverheadGrowth = baseOverheadGrowth + (range * 0.2);  // costs up in bear
const bullOverheadGrowth = baseOverheadGrowth - (range * 0.2);  // costs down in bull

// Exit multiple: ±0.5x per 10pp of range
const bearExitMultiple = baseExitMultiple - (range / 10) * 0.5;  // lower exit in bear
const bullExitMultiple = baseExitMultiple + (range / 10) * 0.5;  // higher exit in bull
