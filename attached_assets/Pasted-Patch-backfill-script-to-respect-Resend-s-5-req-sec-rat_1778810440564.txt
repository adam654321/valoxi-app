Patch backfill script to respect Resend's 5 req/sec rate limit.

The issue: each upsertContact call makes up to 8 Resend API calls (get + create-or-update + 6 segment add/remove operations). With p-limit(5) concurrent users, we burst 40+ calls in one second. Resend caps at 5/sec and rate-limits the rest.

Two changes:

Edit 1 — lower concurrency from 5 to 1.

Find:
  const limiter = pLimit(5);

Replace with:
  const limiter = pLimit(1);

Edit 2 — add 250ms delay between users to give Resend's 5/sec window time to refill.

Find:
  const tasks = targetUsers.map((u) => limiter(async () => {
    const result = await marketingContactsService.upsertContact(u.id);
    tally[result.status] = (tally[result.status] ?? 0) + 1;

    const tag = result.status.toUpperCase().padEnd(8);
    console.log(`[${tag}] user ${String(u.id).padStart(4)} ${u.email}${result.reason ? ` (${result.reason})` : ''}`);

    if (result.status === 'failed') {
      failures.push({ id: u.id, email: u.email, reason: result.reason });
    }
    if (result.status === 'skipped') {
      skips.push({ id: u.id, email: u.email, reason: result.reason });
    }
  }));

Replace with:
  const tasks = targetUsers.map((u, idx) => limiter(async () => {
    // Wait 250ms before each user except the first, so we stay under
    // Resend's 5 req/sec cap given upsertContact makes up to 8 API calls per user.
    if (idx > 0) {
      await new Promise((resolve) => setTimeout(resolve, 250));
    }

    const result = await marketingContactsService.upsertContact(u.id);
    tally[result.status] = (tally[result.status] ?? 0) + 1;

    const tag = result.status.toUpperCase().padEnd(8);
    console.log(`[${tag}] user ${String(u.id).padStart(4)} ${u.email}${result.reason ? ` (${result.reason})` : ''}`);

    if (result.status === 'failed') {
      failures.push({ id: u.id, email: u.email, reason: result.reason });
    }
    if (result.status === 'skipped') {
      skips.push({ id: u.id, email: u.email, reason: result.reason });
    }
  }));
