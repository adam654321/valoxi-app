CONTEXT
The bug: users.onboarding_completed is written by BOTH the setup wizard
"Tell us about yourself" /complete endpoint AND by the activation checklist
/checklist-complete endpoint, and is read by BOTH the App.tsx route guard /
magic link redirect (correctly) AND the dashboard activation checklist gate
(incorrectly). When a new user finishes the setup wizard, onboarding_completed
flips to true, the dashboard gate hides the checklist permanently, and the
checklist /progress endpoint short-circuits with all 7 steps marked true.

The fix direction: introduce users.checklist_completed (boolean, default false,
not null), repoint activation-checklist read/write surfaces to the new column,
leave onboarding_completed and all auth/route-guard call sites untouched. This
prompt is verifying the surfaces and confirming nothing has drifted since the
fresh export was taken.
