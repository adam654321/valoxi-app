**3. Chart-ready waterfall data for the stacked bar chart:**

Build this as an array of objects, one per year. Each object has:
- `name`: `"Y1"`, `"Y2"`, etc.
- For the waterfall visualisation, use a **floating bar** approach. Each bar segment needs a `start` and `end` value so they stack from EBITDA downward:

```tsx
const chartData = useMemo(() => {
  return waterfallData.map(w => {
    // Start from EBITDA, subtract each item to show the waterfall
    const afterTax = w.ebitda + w.tax; // tax is negative
    const afterInterest = afterTax + w.interest; // interest is negative
    const afterPrincipal = afterInterest + w.principalRepayments; // negative
    const afterCapex = afterPrincipal + w.capex; // negative
    const afterWC = afterCapex + w.workingCapitalChange; // negative

    return {
      name: `Y${w.year}`,
      ebitda: w.ebitda,
      tax: w.tax,
      interest: w.interest,
      principal: w.principalRepayments,
      capex: w.capex,
      workingCapital: w.workingCapitalChange,
      freeCashFlow: w.freeCashFlow,
      // For stacked display
      segments: [
        { label: 'Tax', value: w.tax, color: 'hsl(0, 72%, 51%)' },
        { label: 'Interest', value: w.interest, color: 'hsl(25, 95%, 53%)' },
        { label: 'Principal', value: w.principalRepayments, color: 'hsl(45, 93%, 47%)' },
        { label: 'Capex', value: w.capex, color: 'hsl(262, 83%, 58%)' },
        { label: 'WC Change', value: w.workingCapitalChange, color: 'hsl(199, 89%, 48%)' },
      ],
    };
  });
}, [waterfallData]);
```

**4. Summary metrics:**
```tsx
const summaryMetrics = useMemo(() => {
  const totalInterest = waterfallData.reduce((sum, w) => sum + Math.abs(w.interest), 0);
  const totalPrincipal = waterfallData.reduce((sum, w) => sum + Math.abs(w.principalRepayments), 0);
  const totalTax = waterfallData.reduce((sum, w) => sum + Math.abs(w.tax), 0);
  const totalCapex = waterfallData.reduce((sum, w) => sum + Math.abs(w.capex), 0);
  const totalFCF = waterfallData.reduce((sum, w) => sum + w.freeCashFlow, 0);
  const cumulativeFCF: number[] = [];
  let running = 0;
  for (const w of waterfallData) {
    running += w.freeCashFlow;
    cumulativeFCF.push(running);
  }
  const allPositive = waterfallData.every(w => w.freeCashFlow > 0);
  return { totalInterest, totalPrincipal, totalTax, totalCapex, totalFCF, cumulativeFCF, allPositive };
}, [waterfallData]);
```

**B) Chart view** — a grouped/stacked bar chart showing, for each projected year:

Use Recharts `BarChart` with **individual bars per cost category** side by side or stacked. The simplest clear approach:

- Render a **simple stacked bar chart** where:
  - One tall green bar = EBITDA
  - Stacked red/orange bars on the negative side = Tax, Interest, Principal, Capex, WC Change
  - A separate bar or overlaid line = Free Cash Flow (the net result)

**Recommended approach**: Use a `ComposedChart` with:
- A positive green `Bar` for EBITDA
- Negative stacked bars for each deduction (tax, interest, principal, capex, WC)
- A `Bar` for Free Cash Flow in a distinct colour (emerald-500) shown separately

Here is the specific chart implementation to use:


Render with:
```tsx
<BarChart data={barChartData} stackOffset="sign">
```

Using `stackOffset="sign"` groups positive values upward and negative values downward automatically. Stack all items together:

- `EBITDA` — `fill: hsl(142, 71%, 45%)` (green)
- `Tax` — `fill: hsl(0, 72%, 51%)` (red)
- `Interest` — `fill: hsl(25, 95%, 53%)` (orange)
- `Debt Repayment` — `fill: hsl(45, 93%, 47%)` (amber)
- `Capex` — `fill: hsl(262, 83%, 58%)` (purple)
- `WC Change` — `fill: hsl(199, 89%, 48%)` (blue)

Then overlay `Free Cash Flow` as a **separate non-stacked bar** with `stackId` omitted so it floats independently:
- `fill: hsl(160, 84%, 39%)` (emerald)
- `barSize={20}` to make it narrower than the stack

All stacked bars share `stackId="waterfall"`. The FCF bar has no `stackId`.
