PHASE 4C-1 CHUNK 1 OF 2 — Public config endpoint for Clerk flag

GOAL
Expose a single unauthenticated endpoint at GET /api/v2/public/config that returns whether Clerk auth is enabled. Frontend will use this to decide whether to register Clerk sign-in and sign-up routes. CLERK_ENABLED stays false in Secrets. This chunk is backend only.

STEP 1 — Create server/routes/public.routes.ts

FILE: server/routes/public.routes.ts

import { Router } from 'express';
import { asyncHandler } from '../utils/async-handler';
import { sendSuccess } from '../utils/response';

const router = Router();

router.get(
  '/config',
  asyncHandler(async (_req, res) => {
    sendSuccess(res, {
      clerkEnabled: process.env.CLERK_ENABLED === 'true',
    });
  }),
);

export default router;

Notes
- Router-level path is /config. Mount path below is /api/v2/public, giving the final URL /api/v2/public/config.
- No isAuthenticated, no validateCsrfToken, no rate limiter beyond the generalLimiter that is already global on /api/.
- clerkEnabled is computed on every request. Flag reads at request time, not module load time, so a Secrets change after restart is picked up without a code change.

STEP 2 — Register the route in server/routes/index.ts

Add the import alongside the other route imports, grouped with the public-prefixed routes:

import publicConfigRoutes from './public.routes';

Inside registerModularRoutes, add this line. Place it near the other /api/v2/public/* mounts for consistency. A sensible location is immediately after the webhooksRoutes registration and before the billingWebhookRoutes line, since it is an unauthenticated public route with no middleware:

  app.use('/api/v2/public/config', publicConfigRoutes);

Do not wrap with isAuthenticated, validateCsrfToken or portalLimiter. It is intentionally bare.
