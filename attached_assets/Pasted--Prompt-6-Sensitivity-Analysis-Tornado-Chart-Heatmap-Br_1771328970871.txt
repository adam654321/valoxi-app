
It returns:

```typescript
interface SensitivityResult {
  tornadoData: Array<{
    variable: string;
    baseValue: number;      // the base total return
    lowValue: number;       // the low input value (e.g. revenue growth -5%)
    highValue: number;      // the high input value
    lowOutput: number;      // total return at low input
```

The tornado chart is a **horizontal bar chart** showing which variables have the most impact on total return.

The `data.tornadoData` array is already sorted by impact (widest range first). Transform it for the chart:

```tsx
const tornadoChartData = useMemo(() => {
  return data.tornadoData.map(t => ({
    variable: t.variable,
    lowSpread: t.lowOutput - t.baseValue,  // negative number (worse outcome)
```

### Tab 2: Two-Variable Heatmap (`<TabsContent value="heatmap">`)

This is a coloured data table (NOT a recharts chart). Render it as an HTML table.

**Data**: `data.heatmapData` provides `rowValues` (Revenue Growth %), `colValues` (Exit Multiple), and `cells` (2D array of total return values).

**Colour scale**: Compute min and max across all cells, then assign a gradient:

```tsx
const heatmapRange = useMemo(() => {
  const allVals = data.heatmapData.cells.flat();
  return { min: Math.min(...allVals), max: Math.max(...allVals) };
}, [data.heatmapData]);

function getCellColor(value: number): string {
  const { min, max } = heatmapRange;
  if (max === min) return 'hsl(210, 20%, 95%)';
  const ratio = (value - min) / (max - min);
  // Red (0) → Yellow (0.5) → Green (1.0)
  if (ratio <= 0.5) {
    const t = ratio / 0.5;
    const h = 0 + t * 45; // hue 0 (red) to 45 (yellow)
    return `hsl(${h}, 75%, ${85 - t * 10}%)`;
  } else {
    const t = (ratio - 0.5) / 0.5;
    const h = 45 + t * 97; // hue 45 (yellow) to 142 (green)
    return `hsl(${h}, 75%, ${75 - t * 10}%)`;
  }
}
```

**Rendering:**

```tsx
<div className="overflow-x-auto">
  <table className="w-full text-xs border-collapse">
    <thead>
      <tr>
        <th className="p-2 text-left font-medium text-muted-foreground border-b">
          {data.heatmapData.rowVariable} ↓ / {data.heatmapData.colVariable} →
        </th>
        {data.heatmapData.colValues.map((col, ci) => (
          <th
            key={ci}
            className={`p-2 text-center font-medium border-b min-w-[80px] ${
              ci === data.heatmapData.baseColIndex
                ? 'bg-blue-50 dark:bg-blue-950/30 text-blue-700 dark:text-blue-300'
                : 'text-muted-foreground'
            }`}
          >
            {col.toFixed(1)}x
          </th>
        ))}
      </tr>
    </thead>
    <tbody>
      {data.heatmapData.rowValues.map((row, ri) => (
        <tr key={ri}>
          <td
            className={`p-2 font-medium border-b ${
              ri === data.heatmapData.baseRowIndex
                ? 'bg-blue-50 dark:bg-blue-950/30 text-blue-700 dark:text-blue-300'
                : 'text-muted-foreground'
            }`}
          >
            {row.toFixed(1)}%
          </td>
          {data.heatmapData.colValues.map((_, ci) => {
            const cellValue = data.heatmapData.cells[ri][ci];
            const isBase = ri === data.heatmapData.baseRowIndex && ci === data.heatmapData.baseColIndex;
            return (
              <td
                key={ci}
                className={`p-2 text-center font-mono border-b transition-colors ${
                  isBase ? 'ring-2 ring-blue-500 ring-inset font-bold' : ''
                }`}
                style={{ backgroundColor: getCellColor(cellValue) }}
              >
                <TooltipProvider delayDuration={100}>
                  <Tooltip>
                    <TooltipTrigger asChild>
                      <span className="cursor-default text-gray-800 dark:text-gray-900">
                        {Math.abs(cellValue) >= 1000000
                          ? `£${(cellValue / 1000000).toFixed(1)}M`
                          : `£${(cellValue / 1000).toFixed(0)}K`}
                      </span>
                    </TooltipTrigger>
                    <TooltipContent>
                      <p className="text-xs">
                        Rev Growth: {row.toFixed(1)}% / Exit Multiple: {data.heatmapData.colValues[ci].toFixed(1)}x
                      </p>
                      <p className="text-xs font-mono font-bold">{formatCurrency(cellValue)}</p>
                      {isBase && <p className="text-[10px] text-blue-600">Current base case</p>}
                    </TooltipContent>
                  </Tooltip>
                </TooltipProvider>
              </td>
            );
          })}
        </tr>
      ))}
    </tbody>
  </table>
</div>
```

### Tab 3: Break-Even Thresholds (`<TabsContent value="breakeven">`)

Three metric cards in a `grid grid-cols-1 sm:grid-cols-3 gap-4` layout.

**Card 1: Revenue Decline to DSCR < 1.0**
- Icon: `TrendingDown` (h-6 w-6)
- Icon colour: based on severity — if value >= 15 green, >= 10 blue, >= 5 amber, < 5 red
- Title: "Revenue Decline to Breach DSCR" (text-xs text-muted-foreground)
- Value: `data.breakEvenRevDeclineDSCR.toFixed(1)%` decline (text-xl font-bold)
- Interpretation text (text-[11px] text-muted-foreground): "Revenue can fall {value}% before annual debt service coverage drops below 1.0x"
- Card styling: `rounded-lg border p-5`, with a coloured left border matching severity

**Card 2: Revenue Decline to Negative FCF**
- Icon: `AlertTriangle` (h-6 w-6)
- Same severity colouring
- Title: "Revenue Decline to Negative FCF"
- Value: `data.breakEvenRevDeclineFCF.toFixed(1)%` decline
- Interpretation: "Revenue can fall {value}% before free cash flow turns negative in any year"

**Card 3: Interest Rate Headroom**
- Icon: `Percent` (h-6 w-6)
- Severity: if value >= 5 green, >= 3 blue, >= 1.5 amber, < 1.5 red
- Title: "Interest Rate Headroom"
- Value: `+{data.breakEvenInterestRateIncrease.toFixed(1)}%` (text-xl font-bold)
- Interpretation: "Interest rates can increase {value} percentage points before DSCR drops below 1.0x"

Compute `overallRiskColor`, `overallRiskLabel`, and `overallRiskDescription` based on the weakest break-even metric:

```tsx
const overallRisk = useMemo(() => {
  const worstRevDecline = Math.min(data.breakEvenRevDeclineDSCR, data.breakEvenRevDeclineFCF);
  const rateHeadroom = data.breakEvenInterestRateIncrease;

  if (worstRevDecline >= 15 && rateHeadroom >= 5) {
    return {
      color: 'text-green-600',
      label: 'Strong Downside Protection',
      description: 'The deal structure provides substantial margin of safety across revenue decline and interest rate scenarios.',
    };
  } else if (worstRevDecline >= 10 && rateHeadroom >= 3) {
    return {
      color: 'text-blue-600',
      label: 'Adequate Downside Protection',
      description: 'Reasonable headroom exists but a significant downturn could pressure debt covenants.',
    };
  } else if (worstRevDecline >= 5 && rateHeadroom >= 1.5) {
    return {
      color: 'text-amber-600',
      label: 'Limited Downside Protection',
      description: 'Thin margins of safety. A moderate revenue decline or rate increase could breach covenants.',
    };
  } else {
    return {
      color: 'text-red-600',
      label: 'Weak Downside Protection',
      description: 'Very limited headroom. Even a small revenue decline or rate increase could cause distress. Consider reducing leverage.',
    };
  }
}, [data]);
```
