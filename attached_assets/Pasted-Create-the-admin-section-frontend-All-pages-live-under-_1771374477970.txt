Create the admin section frontend. All pages live under /admin routes and are only accessible to users where isSystemAdmin is true.

1. Add isSystemAdmin to the auth hook. Update client/src/hooks/useAuth.ts to also return isSystemAdmin boolean from the /api/v2/auth/me response (the server already returns the user object — just expose the field).

2. Create an AdminRoute guard component at client/src/components/admin-route.tsx. It should use useAuth, redirect to / if !isAuthenticated, and show a 403 message if isAuthenticated but !isSystemAdmin.

3. Create a minimal admin layout at client/src/components/admin-layout.tsx with a left sidebar containing navigation links to: Overview, Token Usage, Platform Costs, Companies, Users, Webhook Events. Include a clear visual indicator that this is the admin panel (different colour scheme from main app — use a dark slate background for the sidebar).

4. Create these pages under client/src/pages/admin/:

admin/index.tsx — Overview dashboard
- Total platform cost this month (Google API + manual costs combined) in a prominent card
- Cost breakdown: Google API vs Manual entries, shown as a simple bar or donut chart using recharts
- Total token calls this month and total tokens consumed
- Active companies count and active users count  
- Table: Top 5 companies by estimated cost this month with columns: Company, Tokens Used, Estimated Cost

admin/token-usage.tsx — Token drill-down
- Three tabs: By Company / By Deal / By Service
- Date range picker (from/to) that filters all three tabs
- Each tab shows a table with: name, prompt tokens, candidate tokens, total tokens, estimated cost USD
- Costs formatted to 4 decimal places with $ prefix
- Total row at the bottom of each table

admin/costs.tsx — Platform costs
- Table of all platform_costs entries: Date Range, Type, Provider, Description, Amount
- Monthly total cards at top: Google API total, Replit total, Other total, Grand Total
- Button to open a modal/dialog to add a new cost entry
- Add cost form fields: Cost Type (select: google_api/replit_storage/replit_compute/other), Provider, Description, Period Start, Period End, Amount (USD), Notes
- Form validated client-side with react-hook-form and zod

admin/companies.tsx — All tenants
- Table: Company Name, Users, Deals, Total Token Cost, Last Active
- Click row to go to admin/companies/:id

admin/companies/[id].tsx — Single tenant detail
- Company info header
- Token usage summary for this company (by service breakdown)
- User list for this company

admin/users.tsx — All users
- Table: Name, Email, Company, Role, System Admin (badge), Last Login, Status

5. Add admin routes to client/src/App.tsx wrapped in the AdminRoute guard:
- /admin → admin/index.tsx
- /admin/token-usage → admin/token-usage.tsx  
- /admin/costs → admin/costs.tsx
- /admin/companies → admin/companies.tsx
- /admin/companies/:id → admin/companies/[id].tsx
- /admin/users → admin/users.tsx

Admin routes should NOT use the main app Layout component — use AdminLayout instead.

6. Add a small "Admin" link in the main app navigation (client/src/components/layout.tsx) that only renders if the current user's isSystemAdmin is true. Link it to /admin.
